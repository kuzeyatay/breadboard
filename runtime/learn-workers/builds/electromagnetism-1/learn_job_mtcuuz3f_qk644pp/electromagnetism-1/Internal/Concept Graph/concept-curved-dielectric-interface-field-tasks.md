## ConceptNode: Curved Dielectric Interface Field Tasks

Planning node for [[curved-dielectric-interface-field-tasks|1.77 Curved Dielectric Interface Field Tasks]].

Source: [[engineering-electromagnetics-9th-ed-9nbsped-compress|Engineering Electromagnetics, Ninth Edition: Learning Spine and Vector Analysis Foundations]]

Locations: Page 156, Chapter 5 Problems 5.31 through 5.35

Problems 5.31 through 5.35 extend dielectric boundary reasoning to planar, cylindrical, spherical, and wedge-shaped interfaces. The procedures require resolving an incident field into normal and tangential components at each point, applying continuity conditions, and transforming the result back into the requested coordinate components. A cylindrical dielectric in a uniform external field illustrates how the interface normal varies with azimuth. A sphere requires both spherical-coordinate decomposition and specialization to selected angular planes. The oblique planar-interface problem uses a plane normal derived from $x-y+2z=5$, while the dielectric-wedge problem tests a boundary where a radial electric field is tangential to constant-$\phi$ interfaces. These tasks emphasize that boundary conditions are local: the same normal and tangential laws apply even when the interface orientation changes from point to point.

### Key planning details

- Curved-interface problems use local normal and tangential directions.
- Vector fields may need conversion between rectangular, cylindrical, and spherical coordinates.
- An oblique plane's normal comes from the coefficients in its surface equation.
- The field inside a dielectric cylinder or sphere can differ in magnitude and direction from the incident field.
- Energy calculations in dielectric wedges use the field appropriate to each permittivity region.

### Source coverage

- Problem 5.31 places a dielectric cylinder on the $z$ axis under $\mathbf E=E_0\mathbf a_x$.
- Problem 5.31 asks for an $\epsilon_r$ that turns a field line incident at $\phi=135^\circ$ to an interior direction $22.5^\circ$ from the $x$ axis.
- Problem 5.33 uses the plane $x-y+2z=5$ with $\epsilon_{r1}=2$ and $\epsilon_{r2}=8$.
- Problem 5.34 treats a dielectric sphere in the field $E_0\mathbf a_x$.
- Problem 5.35 uses dielectric wedges with $\epsilon_{r1}=2$, $\epsilon_{r2}=5$, and $\mathbf E_1=(2000/\rho)\mathbf a_\rho$ V/m.
