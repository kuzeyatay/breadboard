## ConceptNode: Scalar and Vector Quantities

Planning node for [[scalar-and-vector-quantities|1.4 Scalar and Vector Quantities]].

Source: [[engineering-electromagnetics-9th-ed-9nbsped-compress|Engineering Electromagnetics, Ninth Edition: Learning Spine and Vector Analysis Foundations]]

Locations: Page 13, Page 14

A scalar is a quantity represented by one positive or negative real number, whereas a vector requires both a magnitude and a direction in space. Distance, time, temperature, coordinate values, mass, density, pressure, volume, volume resistivity, and voltage are given as scalar examples. Force, velocity, acceleration, and a directed line between battery terminals are vector examples. The distinction is not merely typographical because vector operations depend on direction as well as numerical size. In printed notation, vectors are represented using boldface and scalars using italic type. In handwritten work, an arrow or line over a symbol marks it as a vector. The text warns that omitting this distinction is a major source of vector-analysis errors. Although the book focuses on two-dimensional and three-dimensional spaces, it notes that vectors can be defined in spaces with an arbitrary number of dimensions. This scalar-vector distinction is prerequisite to fields, vector components, and vector products.

### Key planning details

- A scalar is represented by one real number.
- A vector has both magnitude and spatial direction.
- Mass, density, pressure, volume, resistivity, and voltage are scalar quantities.
- Force, velocity, and acceleration are vector quantities.
- Printed vectors use boldface while printed scalars use italic type.
- Handwritten vectors require an arrow or line marker.
- Careless vector notation is identified as a common cause of errors.

### Source coverage

- The text classifies $L$, $t$, $T$, $x$, $y$, and $z$ as scalars.
- Force, velocity, acceleration, and a directed battery-terminal line are listed as vectors.
- The text defines a vector through magnitude and direction in space.
- A caution identifies omitted vector markings as the first pitfall and a major source of errors.
