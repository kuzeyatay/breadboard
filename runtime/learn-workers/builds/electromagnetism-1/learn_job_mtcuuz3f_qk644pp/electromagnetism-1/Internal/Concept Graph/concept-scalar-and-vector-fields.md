## ConceptNode: Scalar and Vector Fields

Planning node for [[scalar-and-vector-fields|1.5 Scalar and Vector Fields]].

Source: [[engineering-electromagnetics-9th-ed-9nbsped-compress|Engineering Electromagnetics, Ninth Edition: Learning Spine and Vector Analysis Foundations]]

Locations: Page 14, Page 20

A field assigns a quantity to every point in a spatial region. A scalar field assigns one scalar value at each point, while a vector field assigns a magnitude and direction at each point. Temperature and density within the Earth are scalar-field examples. Gravitational and magnetic fields, a cable's voltage gradient, and the temperature gradient in a soldering-iron tip are vector-field examples. The field concept is inherently regional because the assigned quantity is defined throughout a set of points rather than only at one isolated location. A field may vary with position and time. Using the position vector $\mathbf{r}$, the text writes a vector field as $\mathbf{G}(\mathbf{r})$ and a scalar field as $T(\mathbf{r})$. In rectangular coordinates, the components of a vector field may each depend on $x$, $y$, and $z$. This definition provides the bridge from elementary vectors to electromagnetic field quantities that vary throughout space.

### Key planning details

- A field defines a quantity at every point in a region.
- A scalar field returns one scalar value at each point.
- A vector field returns a vector at each point.
- Fields may vary with position and time.
- Temperature and density are examples of scalar fields.
- Gravitational, magnetic, and gradient fields are vector fields.
- Functional notation distinguishes $\mathbf{G}(\mathbf{r})$ from $T(\mathbf{r})$.
