# 1.132 Mutual Inductance and Reciprocity

Source: [[engineering-electromagnetics-9th-ed-9nbsped-compress|Engineering Electromagnetics, Ninth Edition: Learning Spine and Vector Analysis Foundations]]

Locations: Page 282, Page 283, Section 8.10.3, Example 8.9

Mutual inductance measures how current in one circuit creates flux linkage in another. If current $I_1$ produces flux $\Phi_{12}$ that links each of $N_2$ turns in circuit 2, then $M_{12}=N_2\Phi_{12}/I_1$. An equivalent field-overlap expression is $M_{12}=(I_1I_2)^{-1}\int_{vol}\mathbf{B}_1\cdot\mathbf{H}_2\,dv$, or, for a linear medium, $M_{12}=(I_1I_2)^{-1}\int_{vol}\mu\mathbf{H}_1\cdot\mathbf{H}_2\,dv$. The symmetry of the dot product shows that $M_{12}=M_{21}$. Example 8.9 applies these ideas to two coaxial solenoids with $R_2>R_1$. Only the common cross-sectional area $\pi R_1^2$ contributes to mutual linkage because the smaller solenoid confines the field generated by circuit 1. The result per unit length is $M_{12}=M_{21}=\mu_0n_1n_2\pi R_1^2$. With $n_1=5000$ turns/m, $n_2=8000$ turns/m, and $R_1=0.02$ m, the source obtains 63.2 mH/m. The self-inductances follow separately from each coil's own field and area.

## Core Ideas

- Mutual inductance is based on flux produced by one current and linked by another circuit.
- The flux-linkage definition is $M_{12}=N_2\Phi_{12}/I_1$.
- The energy-overlap definition uses $\mathbf{B}_1\cdot\mathbf{H}_2$.
- For linear media, the overlap integrand may be written $\mu\mathbf{H}_1\cdot\mathbf{H}_2$.
- Reciprocity gives $M_{12}=M_{21}$.
- Only spatially overlapping fields contribute to mutual inductance.
- For coaxial solenoids, the smaller cross-sectional area controls the mutual flux.
- Mutual inductance and magnetization both use the symbol $M$, so context distinguishes them.
