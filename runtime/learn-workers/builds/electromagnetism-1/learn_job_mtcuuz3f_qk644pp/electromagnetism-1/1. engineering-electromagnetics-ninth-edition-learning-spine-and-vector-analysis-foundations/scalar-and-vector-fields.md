# 1.5 Scalar and Vector Fields

Source: [[engineering-electromagnetics-9th-ed-9nbsped-compress|Engineering Electromagnetics, Ninth Edition: Learning Spine and Vector Analysis Foundations]]

Locations: Page 14, Page 20

A field assigns a quantity to every point in a spatial region. A scalar field assigns one scalar value at each point, while a vector field assigns a magnitude and direction at each point. Temperature and density within the Earth are scalar-field examples. Gravitational and magnetic fields, a cable's voltage gradient, and the temperature gradient in a soldering-iron tip are vector-field examples. The field concept is inherently regional because the assigned quantity is defined throughout a set of points rather than only at one isolated location. A field may vary with position and time. Using the position vector $\mathbf{r}$, the text writes a vector field as $\mathbf{G}(\mathbf{r})$ and a scalar field as $T(\mathbf{r})$. In rectangular coordinates, the components of a vector field may each depend on $x$, $y$, and $z$. This definition provides the bridge from elementary vectors to electromagnetic field quantities that vary throughout space.

Our work will mainly concern scalar and vector $\textit{fields}$. A field (scalar or vector) may be defined mathematically as some function that connects an arbitrary origin to a general point in space. We usually associate some physical effect with a field, such as the force on a compass needle in the earth's magnetic field, or the movement of smoke particles in the field defined by the vector velocity of air in some region of space. Note that the field concept invariably is related to a region. Some quantity is defined at every point in a region. Both $\textit{scalar fields}$ and $\textit{vector fields}$ exist. The temperature and the density at any point in the earth are examples of scalar fields. The gravitational and magnetic fields of the earth, the voltage gradient in a cable, and the temperature gradient in a soldering-iron tip are examples of vector fields. #### 1.5 THE VECTOR FIELD

We have defined a vector field as a vector function of a position vector. In general, the magnitude and direction of the function will change as we move throughout the region, and the value of the vector function must be determined using the coordinate values of the point in question. In the rectangular coordinate system, the vector will be a function of the variables $x$, $y$, and $z$.

Again, representing the position vector as $\mathbf{r}$, a vector field $\mathbf{G}$ can be expressed in functional notation as $\mathbf{G}(\mathbf{r})$; a scalar field $T$ is written as $T(\mathbf{r})$.

## Core Ideas

- A field defines a quantity at every point in a region.
- A scalar field returns one scalar value at each point.
- A vector field returns a vector at each point.
- Fields may vary with position and time.
- Temperature and density are examples of scalar fields.
- Gravitational, magnetic, and gradient fields are vector fields.
- Functional notation distinguishes $\mathbf{G}(\mathbf{r})$ from $T(\mathbf{r})$.
