# web_grounding

This turn requires current external evidence. Use `web_search` before making factual claims, then use `web_extract` when the search result alone does not support the answer. Prefer primary or official sources and include the source URLs in the answer.

Do not substitute WorldMonitor, the capability catalogue, a skill search, or a terminal command for web research. They do not verify a general web fact. If the first search is poor, try at most one materially different query. If no web result supports the answer, say that live verification is unavailable and do not fill the gap from memory.
