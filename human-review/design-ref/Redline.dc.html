Product spec · draft 3

Redline

Review and edit agent-generated HTML in the browser, then send the whole batch back to your agent.

Problem

People who work with coding agents increasingly receive work as HTML artifacts: specs, plans, reports, newsletter drafts, landing pages. But the review loop is stuck in the terminal — you open the file, spot ten problems, then type a long prose message describing each one. Small copy fixes that would take five seconds to make yourself cost a full agent round-trip.

Solution

A CLI that opens any HTML file in a local browser where you edit text directly, delete elements, and leave Google Docs-style comments on highlighted text — then submits the whole batch to whatever agent you use, which fixes the file and hot-reloads the page.

Scope: Local single-user review of one HTML file per session. Commenting and editing, batch feedback to any shell-capable agent, npm-distributed CLI. No hosting, no multiplayer, no accounts.
