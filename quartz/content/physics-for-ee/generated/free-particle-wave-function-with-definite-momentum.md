## Free Particle Wave Function with Definite Momentum

Source: [[983068-english-1|Schrodinger Equation, Wave Functions, and Probability Interpretation]]

Locations: Page 13, Page 14

The lecture uses a free particle with definite momentum as an example of a simple Schrodinger solution. Such a particle has momentum $\hbar k$ and an energy, and its wave function at time zero is described as extending over all space. The example specifically mentions $\cos(kx)$, which has values for the entire range of $x$. Because the wave exists from $-\infty$ to $+\infty$, it does not provide a localized position for the particle. The lecturer says this is very inconvenient if the question is where to find the particle. This example motivates the need for wave packets: a single traveling wave can represent a definite wave number or momentum, but it fails to represent a particle localized in a finite spatial region.

### Key points

- A free particle with definite momentum has momentum $\hbar k$.
- The lecture also associates the free particle state with an energy.
- At time zero, the wave function extends over all space.
- $\cos(kx)$ has values over the whole $x$ range.
- The wave extends from $-\infty$ to $+\infty$.
- A single traveling wave does not determine where the particle is.
- This lack of localization motivates forming a wave packet.
