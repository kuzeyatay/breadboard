## Measurement and Wave Function Collapse

Source: [[986217-english-1|Quantum Entanglement, Bell Inequality, and Course Summary]]

Locations: Page 14

The lecture connects entanglement to the concept of wave function collapse. Before measurement, an entangled system can be described as a superposition of possible wave function states. When a measurement occurs, the system collapses to one of the possible solutions. In the sock analogy, this corresponds to the indefinite shared state becoming a definite measurement result such as pink for one sock and blue for the other. The lecture uses the phrase 'when you do a measurement the wave function collapses to one of the two solutions' and explicitly identifies this as wave function collapse. Collapse is also described as the process by which entangled objects become disentangled into definite measured outcomes.

### Key points

- An entangled system can be in a superposition of possible wave function states.
- Measurement collapses the wave function to one solution.
- Wave function collapse produces definite measurement outcomes.
- Measurement also disentangles previously shared quantum states.
- The sock analogy represents collapse as indefinite colors becoming definite opposite colors.
- Collapse is tied to the broader lecture theme of wave functions and measurement.
