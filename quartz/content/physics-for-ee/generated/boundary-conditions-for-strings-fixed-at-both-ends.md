## Boundary Conditions for Strings Fixed at Both Ends

Source: [[974965-english-1|Standing Waves, Reflection, and Resonance on Strings]]

Locations: Page 12

For a string fixed at both ends, only certain wavelengths can form standing waves because the endpoints must remain nodes. The lecture states that when the spatial part $Kx$ is a multiple of $\pi$, such as $0, \pi, 2\pi, 3\pi$, a standing wave condition is met. Since the wave number is $K = 2\pi/\lambda$, the string length can be related to the wavelength. The fixed-end condition requires the string length to contain an integer number of half-wavelengths. This gives the allowed-mode condition $$L = n\frac{\lambda}{2}, \quad n = 1,2,3,\ldots$$ The case $n=0$ is a trivial solution because the wave does not move, so it is not considered an oscillation.

### Key points

- A string fixed at both ends must have nodes at both endpoints.
- Standing waves occur when the spatial phase $Kx$ reaches multiples of $\pi$.
- The wave number relation is $K = 2\pi/\lambda$.
- The string length must be an integer multiple of half a wavelength.
- The allowed-length condition is $L = n\lambda/2$.
- Allowed mode numbers are $n = 1,2,3,\ldots$ for nontrivial oscillations.
- The $n=0$ case is excluded because it corresponds to no oscillation.
