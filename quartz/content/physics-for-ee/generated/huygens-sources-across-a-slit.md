## Huygens Sources Across a Slit

Source: [[979070-english|Diffraction, Interference, and Course Feedback]]

Locations: Page 16

The lecture explains single-slit diffraction by treating every point in the slit as a Huygens source. If one zooms in on the slit, any point within the opening can emit a secondary wavelet. These many sources form a continuum, unlike the two-source model used for two-slit interference. At a distant point $P$ on the screen, the waves from all these sources may interfere constructively or destructively depending on their path differences. Constructive interference occurs when path differences equal integer multiples of the wavelength. Destructive interference occurs when pairs or groups of contributions cancel. This Huygens-source picture is the conceptual bridge from simple interference to diffraction by extended openings.

### Key points

- Every point in a slit can be modeled as a Huygens source.
- A slit therefore behaves like a continuum of coherent wave sources.
- The screen point receives contributions from many points across the slit.
- Constructive interference occurs when path differences are integer multiples of $\lambda$.
- Destructive interference occurs when contributions from different slit regions cancel.
- This model generalizes the two-source interference construction.
