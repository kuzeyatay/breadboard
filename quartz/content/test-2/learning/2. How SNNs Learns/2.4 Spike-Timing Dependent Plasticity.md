### Spike-Timing Dependent Plasticity

After seeing that a spiking neural network communicates through timed events, the natural training question becomes very concrete: if one neuron fires just before another neuron, should the connection between them become stronger? Imagine a small edge device listening for a repeated sound pattern, such as the click of a machine part before a fault. Most of the time the sensor is quiet. When the click appears, a few input neurons spike at particular moments, and a few downstream neurons respond soon after. A learning rule that can use those local moments directly can adapt while spending very little energy, because it only updates connections around the spikes that actually occurred.

Spike-Timing Dependent Plasticity, or STDP, is a learning rule built around this timing relationship. A synaptic weight is the strength of the connection from one neuron to another. A larger weight means a spike arriving from the sending neuron has a stronger effect on the receiving neuron's membrane potential. STDP changes that weight by looking at two events: the presynaptic spike, which comes from the sending neuron, and the postsynaptic spike, which comes from the receiving neuron. The rule asks a simple local question: did the input spike arrive shortly before the output spike, or shortly after it?

When the presynaptic neuron fires shortly before the postsynaptic neuron, the connection is treated as useful for producing that response, so the weight is strengthened. When the presynaptic neuron fires after the postsynaptic neuron, the connection is treated as less useful for causing that response, so the weight is weakened. The learning signal is the time gap between the two spikes. A small timing gap produces a stronger update because the two events are closely linked in time. A large timing gap produces a weaker update because the connection between the events is less direct.

A compact way to describe this is to define the timing difference
$$
\Delta t = t_{\text{post}} - t_{\text{pre}}
$$
Here, $t_{\text{pre}}$ is the time when the presynaptic neuron fires, $t_{\text{post}}$ is the time when the postsynaptic neuron fires, and $\Delta t$ is the postsynaptic spike time minus the presynaptic spike time. If $\Delta t$ is positive, the input spike came before the output spike. If $\Delta t$ is negative, the input spike came after the output spike. This single number lets the learning rule decide both the direction and rough size of the weight change.

For example, suppose an input neuron fires at $12$ ms and the receiving neuron fires at $15$ ms. Then $\Delta t = 15 - 12 = 3$ ms. The input arrived just before the output, so STDP strengthens that synapse. If the input neuron fires at $18$ ms while the receiving neuron fired at $15$ ms, then $\Delta t = 15 - 18 = -3$ ms. The input arrived after the response, so STDP weakens that synapse. The rule feels almost like credit assignment by timing: spikes that arrive just in time to help get more influence, while spikes that arrive too late lose influence.

This timing-based update explains why STDP fits low-power learning. A dense training method usually needs many numerical operations across many weights, often guided by a global error signal. STDP can update a synapse using information available at that synapse: the time of the incoming spike, the time of the outgoing spike, and the current weight. The network can remain quiet when no spike occurs, and quiet periods consume little activity. Learning becomes event-driven: computation happens around sparse spikes rather than continuous streams of values.

The energy pattern follows directly from that sparsity. In the reported comparison across models, a conventional ANN-style CNN uses about $200$ mJ per inference, while an STDP-based SNN uses about $5$ mJ per inference. The same comparison shows spike activity falling to roughly $4{,}000$ spikes per inference for the STDP-based model, compared with about $20{,}000$ spikes for a converted SNN and about $12{,}000$ spikes for a surrogate-gradient SNN. The smaller spike count means fewer event transmissions and fewer synaptic updates. On hardware where movement and processing of events cost energy, fewer spikes translate into a much lighter computation.

**Question.** Why does a lower spike count usually mean lower energy use in an SNN?

**Answer.** A spike triggers communication and computation. When a neuron spikes, the event travels to connected neurons and can cause synaptic updates or membrane-potential changes. If the network solves a task with fewer spikes, fewer events need to be sent and processed. STDP encourages this sparse event-driven style because learning is tied to actual spike timing rather than constant activity across all units.

STDP also helps explain the phrase "unsupervised setting." In supervised training, the network receives an external target, such as "this image is a seven," and adjusts itself to reduce the difference between its prediction and that target. STDP can learn useful structure from the timing of activity itself. If certain input spikes repeatedly arrive just before a neuron responds, those connections become stronger. Over time, neurons can become tuned to recurring temporal patterns in the input. A device that watches a stream of sensor events can therefore adapt to repeated patterns without needing every moment to be labeled by a trainer.

That local freedom comes with a cost: STDP often converges slowly. Convergence means the training process settles into a stable pattern where performance or loss changes less from one epoch to the next. A global optimization method can push many weights in a coordinated direction toward an accuracy target. STDP changes weights through many small local timing events. Each synapse learns from nearby spike pairs, so useful structure emerges gradually through repeated exposure. The convergence behavior reflects this: STDP-based models tend to plateau at higher loss values and require more epochs to stabilize, while surrogate-gradient-trained SNNs reduce loss faster and can stabilize by around the twentieth epoch.

A beginner might wonder why anyone would choose a slower method with lower classification accuracy. The answer depends on the job the network is being asked to do. If the goal is maximum classification performance under a tight latency target, another training method may be a better fit. If the goal is long-running adaptation on an energy-constrained device, STDP becomes attractive because it spends computation only where events occur and learns from local timing. A battery-powered sensor, a neuromorphic edge device, or an always-on monitor may value sparse activity more than squeezing out the last few percentage points of accuracy.

**Question.** Does STDP learn "less" because it uses only local timing?

**Answer.** STDP learns a different kind of structure. It strengthens connections that repeatedly help produce spikes at the right moments, so it can discover temporal regularities in incoming activity. Its local rule gives it energy efficiency and biological plausibility, while its gradual, synapse-by-synapse updates make precise classification and fast convergence harder than methods that optimize a global objective.

The mental model is a set of connections that listen for temporal responsibility. Each synapse asks whether its incoming spike arrived early enough to help the receiving neuron fire. Helpful timing strengthens the pathway; late timing weakens it. Because the rule uses only nearby spike times, learning can happen with sparse events, low spike counts, and very low energy consumption. Because the rule lacks a single global push toward maximum accuracy, improvement unfolds slowly and often settles at a less precise solution. STDP emphasizes low power and local adaptation because its learning signal is timing itself.
