## Limits of CNNs, Recurrent Models, and Transformers

After seeing that different neural networks can be judged by accuracy, latency, energy use, and how they handle time, the natural question becomes why another computing style is needed at all. Imagine a camera watching a hallway where most frames look almost the same. A standard neural network can still spend work on every frame, every pixel region, and every internal activation, even when the scene barely changes. That effort can be useful when the task is recognizing shapes in a single image, but it becomes expensive when the real signal is a pattern unfolding over time: a person starts walking, pauses, turns, and then moves again. The model now needs to understand both where features appear and when they appear.

A Convolutional Neural Network, or CNN, is built around the idea that nearby pieces of an image often belong together. A small filter slides across an image and looks for a local pattern, such as an edge, corner, texture, or curve. Early layers can detect simple patterns; later layers combine them into larger features such as wheels, eyes, or object parts. This ability is called **spatial feature extraction**: the network learns useful structure from positions and neighborhoods in space. In an image, "space" means width and height. In a video frame, it means the arrangement of pixels inside each frame.

A concrete way to picture this is to imagine looking for a face in a photograph. You do not need to inspect every pixel as an unrelated number. You notice that two dark regions arranged above a line-like region may form eyes and a mouth. A CNN formalizes that instinct by learning filters that respond to repeated spatial patterns wherever they occur. This makes CNNs especially strong for image and video processing tasks where the important clue is the shape or arrangement of visual features.

That strength also explains the limitation. A CNN's main tool is spatial pattern detection, so time has to be added indirectly when the task depends on sequence. If a model sees a stack of video frames, it can extract spatial features from each frame, but the meaning of the event may depend on the order of those features. A hand moving up and a hand moving down may contain similar shapes, yet the sequence changes the meaning. Temporal or sequential data asks the model to carry information from earlier steps into later steps. A plain spatial extractor has no built-in memory of what happened before unless the architecture is extended or combined with another method.

This is why one metric cannot choose the winner across all architectures. If the metric is image accuracy on a spatial recognition task, a CNN may look excellent because the task matches its strength. If the task is a long sequence where an early event changes the meaning of a later event, the same spatial strength gives only part of the needed computation. A fair comparison has to ask what kind of structure the model is being asked to learn: spatial structure, temporal structure, or both. Spatial feature extraction is powerful, but it answers a different question from long-term sequence understanding.

**Question.** If CNNs can process video frames, why are they described as spatially strong rather than naturally sequential?

**Answer.** A video frame is still an image, so a CNN can extract shapes, textures, and object parts from each frame. The sequential challenge begins when the meaning depends on how those frame-level features change over time. A CNN can supply the "what is visible here?" part very well, but the "what happened earlier, and how does it affect what this means now?" part requires memory or an additional temporal mechanism.

Recurrent Neural Networks, or RNNs, were designed to handle sequences more directly. An RNN processes one step at a time and carries an internal state forward. The state acts like a running memory: after reading the current input, the network updates its state, then passes that state to the next step. For a sentence, the steps might be words. For sensor data, the steps might be measurements. For video, the steps might be frames or frame features. This design gives the model a way to let earlier information influence later decisions.

The difficulty appears when the relevant information is far away in the sequence. During training, the model learns by passing error signals backward through the sequence so earlier steps can be adjusted. Those signals can shrink as they travel through many repeated updates. This problem is called the **vanishing gradient** problem. A gradient is the training signal that tells a model how to change a parameter to reduce error. When the gradient becomes very small, early parts of the sequence receive weak correction, so the model struggles to learn relationships that span many steps.

A simple example is the sentence, "The keys that the traveler left beside the old map in the station locker were finally found." To understand why "were" fits, a model has to remember that the subject is "keys," even after many intervening words. In a time series, the same kind of issue appears when an early warning sign affects a later outcome. If the training signal fades before it reaches the earlier event, the model may learn nearby patterns while missing the long-range dependency.

LSTM and GRU models were developed to improve this situation by adding gates. A gate is a learned control that decides what information should be kept, updated, or released from memory. These models can preserve useful information better than a basic RNN, especially across longer sequences. Yet they still process sequences step by step, and long-range relationships can remain inefficient to model. The model has to carry and update memory repeatedly, which can become costly as sequences grow or as tasks demand many dependencies across distant positions.

Transformers approach sequence processing differently. Instead of passing a single memory state step by step, they use **attention mechanisms** that let parts of a sequence directly weigh other parts. Attention asks, for a given position, which other positions are relevant right now? In a sentence, a word can attend to another word many tokens earlier. In a sensor stream, a current event can be compared with earlier events without relying only on a compressed recurrent state.

This direct comparison is powerful because long-range dependencies become easier to express. If a late event depends on an early event, attention can create a connection between them during processing. The cost comes from the resources needed to compute and store many such relationships. As sequences become large, the number of possible interactions grows quickly. The model may need substantial memory and processing power to keep track of attention patterns, especially in large language or high-dimensional sequence tasks.

**Question.** Why do Transformers help with long-range dependencies but still motivate interest in another computing style?

**Answer.** Transformers make distant relationships easier to represent because attention can connect far-apart positions directly. That benefit can require large memory and processing resources. When a task involves long streams, sparse events, or low-power hardware, the cost of dense attention can become a serious limitation, so a computing style that spends work only when meaningful events occur becomes attractive.

These limits point toward a shared pressure: each architecture solves one part of the problem while paying a cost somewhere else. CNNs efficiently extract spatial structure, but sequence meaning requires more than spatial filters. RNN-family models bring memory into sequence processing, but training can weaken across long spans and repeated updates can be inefficient. Transformers strengthen long-range dependency modeling through attention, but their memory and processing demands can become large. The motivation for spiking computation begins here: if information often arrives as changes over time, then a model that treats timing and sparse events as part of computation offers a different way to spend resources. The mental model is a chain of tradeoffs: spatial filters find where patterns are, recurrent memory carries what came before, attention compares distant positions, and event-based spikes ask whether computation can happen mainly when something meaningful changes.
