## Convergence and Learning Curves

After looking at accuracy, loss, latency, energy, and spike activity as separate measurements, the natural question becomes: how quickly does a spiking neural network reach useful behavior while it is being trained? Imagine training three models for the same task and checking them after each pass through the data. One model improves sharply in the early passes, another improves more gradually, and a third makes small gains and then settles early. If all three are judged only by their final number, the path they took disappears. A convergence plot keeps that path visible. It shows whether learning happens quickly, slowly, smoothly, or unevenly across epochs.

An **epoch** is one complete pass through the training data. If a model trains for 20 epochs, it has had 20 full opportunities to adjust its internal parameters using the available examples. During those epochs, two measurements are especially useful. **Training loss** measures how far the model's current predictions are from the desired answers during training; lower loss means the model's predictions are becoming better aligned with the training targets. **Training accuracy** measures the fraction of training examples the model classifies correctly; higher accuracy means the model is making more correct decisions. A learning curve places one of these measurements on the vertical axis and epoch number on the horizontal axis, so the shape of the curve becomes a picture of training speed.

A loss curve is easiest to read if you imagine a learner correcting mistakes. At the beginning, the model usually makes many mistakes, so the loss is high. As training changes the model, the loss should fall. A steep downward slope means the model is reducing its mistakes quickly. A shallow downward slope means improvement is happening slowly. A curve that flattens means the model has reached a more stable region where extra epochs bring smaller changes. The table below gives the loss-side view of this process for three SNN training approaches: Converted SNN, Surrogate Gradient SNN, and STDP-based SNN.

![Training loss across epochs for different SNN models](/test-2/assets/source-visuals/2510-27379v1-page-10-table-t1-training-loss-across-epochs-for-different-snn-mo.png)

*Training loss across epochs for different SNN models* *(p. 10)*

The training-loss table should be read row by row across epochs and column by column across models. The epoch column marks training time. The training-loss entries show how much error remains at each stage. The Surrogate Gradient SNN has the steepest and most consistent decline, which means it keeps finding useful changes during training. The Converted SNN improves at a more moderate pace, so its loss still falls but with less urgency. The STDP-based SNN changes more slowly and tends to flatten earlier, which fits its learning style: spike-timing dependent plasticity adjusts based on timing relationships between spikes, so its progress can be gradual and may settle before reaching the same accuracy-oriented behavior as the supervised gradient-based method.

The same story can be shown as a curve. A convergence graph turns the table's numbers into shape. When the curve drops sharply, the model is learning quickly. When the curve drifts downward gently, the model is learning slowly. When it becomes nearly horizontal, the model has mostly stabilized for the current training setup.

![Convergence behavior of SNN models](/test-2/assets/source-visuals/2510-27379v1-page-10-graph-g1-convergence-behavior-of-snn-models.png)

*Convergence behavior of SNN models* *(p. 10)*

This convergence graph lets the eye compare training behavior immediately. The Surrogate Gradient SNN curve falls fastest, showing rapid reduction in training loss. The Converted SNN follows a middle path, improving steadily but reaching stable behavior later. The STDP-based SNN changes more slowly and levels off earlier, showing slower convergence. The shape matters as much as the endpoint: a model whose curve reaches a low-loss region early can become useful with fewer training epochs, while a model whose curve takes longer needs more training time to approach similar stability.

To make "learns quickly" precise, we can use **convergence time**. Choose a **target accuracy**, meaning the accuracy level that counts as good enough for the task. Then look for the earliest epoch at which the model reaches that target. In formula form,
$$
T_{\text{conv}} = \min \{ e : A(e) \ge A_{\text{target}} \}
$$
Here, $T_{\text{conv}}$ is the convergence time, measured in epochs. The symbol $e$ means a particular epoch number. The function $A(e)$ means the model's accuracy at epoch $e$. The value $A_{\text{target}}$ is the chosen target accuracy. The symbol $\min$ means "the smallest," so the formula asks for the earliest epoch where the accuracy is at least the target. This lets you compute training speed from an accuracy curve instead of relying on a vague impression.

For example, suppose the target accuracy is 95%. If the Surrogate Gradient SNN first reaches 95% accuracy at epoch 18, then its convergence time is 18 epochs. If the Converted SNN reaches 95% at epoch 24, its convergence time is 24 epochs. If the STDP-based SNN never reaches 95% within the plotted epochs, then within that training window it has no convergence time for that target. The target accuracy acts like a finish line: the faster model is the one that crosses that line earlier, even if another model later approaches a similar level.

Accuracy curves make this finish-line idea especially clear because they rise instead of fall. At the beginning of training, accuracy is lower. As the model learns, accuracy climbs. A steep upward curve means correct predictions are increasing quickly. A curve that rises slowly means the model needs more epochs to gain reliable performance. A curve that flattens near a high value shows that the model has reached stable accuracy.

![Learning curves showing training accuracy versus epochs for converted, surrogate-gradient, and STDP-based SNNs](/test-2/assets/source-visuals/2510-27379v1-page-11-graph-g1-learning-curves-showing-training-accuracy-versus.png)

*Learning curves showing training accuracy versus epochs for converted, surrogate-gradient, and STDP-based SNNs* *(p. 11)*

In this accuracy-versus-epochs plot, the Surrogate Gradient SNN rises quickly and reaches strong performance by around the 20th epoch. That early rise means its training rule is efficiently shaping spike-based behavior toward the task objective. The Converted SNN also improves, but it typically needs a longer simulation or adjustment window because it begins from an artificial neural network representation and then maps activity into spikes. The STDP-based SNN improves more gradually, reflecting a learning rule driven by spike timing rather than direct supervised error correction. Around epoch 20, the comparison favors the Surrogate Gradient SNN for fast convergence: it has already approached stable, high accuracy while the other approaches are still catching up or plateauing lower.

**Question.** If a model has the highest final accuracy, does it always have the fastest convergence?

**Answer.** Fast convergence depends on when the model reaches a chosen target accuracy, not only where it ends. A model can finish with strong final accuracy but require many epochs to get there. Another model can reach a useful target earlier, giving it a shorter convergence time for that target. The learning curve answers this by showing the full path across epochs.

A common beginner confusion comes from mixing up training loss and training accuracy because one goes down while the other goes up. They are two views of the same learning process. Loss falls as predictions become less wrong. Accuracy rises as more predictions become correct. When training is going well, these curves usually move in opposite directions: the loss curve slopes downward, and the accuracy curve slopes upward. Reading them together gives a stronger judgment than either alone, because low loss and high accuracy both indicate that the model is settling into useful behavior.

**Question.** Why use a target accuracy instead of just saying the curve "looks fast"?

**Answer.** A target accuracy turns visual judgment into a measurable rule. Once the target is chosen, convergence time is the earliest epoch where the accuracy curve reaches that level. This makes it possible to compare Converted SNNs, Surrogate Gradient SNNs, and STDP-based SNNs using the same finish line.

The mental model is a race toward stable useful performance. Epochs are the steps along the track. Training loss shows how quickly mistakes shrink, so faster learning appears as a steeper downward curve. Training accuracy shows how quickly correct predictions accumulate, so faster learning appears as a steeper upward curve. Convergence time places a finish line at a target accuracy and asks when each model reaches it. In the SNN comparison here, surrogate-gradient training reaches strong accuracy quickly, around the 20th epoch, while converted models improve more moderately and STDP-based models settle more slowly. A convergence plot therefore teaches more than final performance; it shows the tempo of learning.
