Imagine a spiking neural network receiving 100 recordings of hand gestures. For each recording, the network predicts a class such as "wave," "clap," or "point." Someone then compares every prediction with the known class. If 93 predictions match and 7 do not, the network has made 93 correct predictions. That count turns a collection of individual outcomes into measurable behavior, but it still depends on how many recordings were evaluated. Ninety-three correct predictions out of 100 indicate strong performance; the same 93 correct predictions out of 1,000 indicate weak performance. A useful evaluation therefore relates the number of correct predictions to the total number of predictions.

This relationship is called **classification accuracy**. It answers a focused question: what fraction of the evaluated examples did the model classify correctly? To derive it, begin with one outcome per example. Assign a value of 1 when the predicted class matches the true class and 0 when it differs. Adding these values across the evaluation set gives the **number of correct predictions**. Counting every evaluated example gives the **total number of predictions**. Dividing the first count by the second produces a ratio that can be compared across evaluation sets of different sizes:
$$
\text{Classification accuracy}
=
\frac{\text{Number of correct predictions}}
{\text{Total number of predictions}}
$$
Here, the **number of correct predictions** is the count of evaluated examples for which the predicted class equals the true class. The **total number of predictions** is the count of all examples included in the evaluation, including both correct and incorrect outcomes. **Classification accuracy** is the resulting fraction of correct outcomes. Multiplying that fraction by $100\%$ expresses the same result as a percentage.

For the gesture example, the calculation is
$$
\text{Classification accuracy}
=
\frac{93}{100}
=
0.93
=
93\%
$$
The numerator, 93, counts only the correct predictions. The denominator, 100, counts the entire evaluation set. The 7 incorrect predictions affect accuracy because they are included in that denominator while adding nothing to the numerator. This gives accuracy an intuitive interpretation: if a result of $93\%$ remains representative, then about 93 of every 100 similar examples would be expected to receive the correct class.

The denominator deserves careful attention. Suppose one model correctly classifies 45 examples and another correctly classifies 900. The larger correct count initially sounds more impressive. If the first model was evaluated on 50 examples, its accuracy is $45/50=90\%$. If the second was evaluated on 1,200 examples, its accuracy is $900/1200=75\%$. Correct prediction count makes performance measurable, while division by the evaluation-set total gives that count its scale. Meaningful interpretation also requires a suitable evaluation set, because the percentage describes performance on the examples that were actually evaluated.

**Question.** If a network makes 240 predictions and has a classification accuracy of $85\%$, how many predictions are correct?

**Answer.** Write $85\%$ as the fraction $0.85$, then multiply it by the total number of predictions:
$$
\text{Number of correct predictions}
=
0.85 \times 240
=
204
$$
The network therefore makes 204 correct predictions. The remaining $240-204=36$ predictions are incorrect.

Accuracy compresses all evaluated classifications into one number. That compression makes it easy to see how often the model reaches the correct class, yet it leaves other aspects of model behavior outside the calculation. A spiking model generates discrete spike events over time, so two models can reach the same accuracy through very different computational behavior. One may produce its answer quickly, while another may require a longer interval of spike activity. One may use relatively few spikes, while another may generate many spikes for each inference. Their energy consumption can also differ, and their learning processes may reach their eventual performance at different rates.

Consider two spiking networks that each classify 950 of 1,000 examples correctly. Both have
$$
\frac{950}{1000}=0.95=95\%
$$
Classification accuracy. The accuracy calculation treats their final predicted classes identically. Now imagine that one network reaches each decision with sparse spike activity and the other uses a much larger number of spikes. Their correct prediction counts remain equal, so their accuracy remains equal. The extra activity appears only when spike count is measured. If one network also takes longer to produce each prediction, that difference appears in latency, the time required to reach an output. If its computation consumes more energy, an energy measurement captures that cost. If its training performance develops more slowly, convergence behavior reveals the difference across training epochs.

This single-metric limitation means that accuracy supports one dimension of evaluation: task success measured as correct classifications per total classifications. Latency describes response speed, energy consumption describes computational energy use, spike count describes the amount of spiking activity, and convergence behavior describes how performance develops during learning. Each measurement answers a different question. Accuracy can establish that a model usually predicts the correct class while remaining silent about how quickly, sparsely, efficiently, or readily it achieves that result.

A common beginner confusion comes from treating the highest accuracy as a complete description of the strongest model. Accuracy establishes which model produces the largest fraction of correct labels on a given evaluation set. Choosing between spiking models requires examining the other behavior relevant to the intended goal as well. A small difference in accuracy may accompany a large difference in latency, energy use, or spike activity. The percentage remains valid; its scope is simply the correctness of the final classifications.

**Question.** Two spiking networks both achieve $94\%$ accuracy. Can accuracy tell which one responds faster or uses fewer spikes?

**Answer.** Accuracy alone gives both networks the same result because both produce the same fraction of correct predictions. Response speed requires a latency measurement, and spiking activity requires a spike-count measurement. Energy consumption and convergence behavior likewise require their own measurements. Accuracy supplies the correctness part of the evaluation rather than those additional dimensions.

The clearest mental model is a scorecard built from distinct questions. Classification accuracy asks, "Out of every prediction evaluated, how many were correct?" The correct prediction count supplies the successful outcomes, the total prediction count supplies the scale, and their ratio produces the accuracy. That ratio gives a compact view of classification success. A fuller view of a spiking network places that correctness measure beside latency, energy consumption, spike activity, and convergence behavior, allowing each metric to describe the part of performance it can directly measure.
