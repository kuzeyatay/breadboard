After measuring what an SNN spends during inference, the next question is how soon it becomes useful while it is still learning. Imagine training three spiking models for the same recognition task. At the start, each model makes many mistakes because its internal parameters have not yet settled into a pattern that separates the input classes well. After one pass through the training data, it improves a little. After another pass, it may improve more. A researcher watching this process needs a way to say, "At what training step did this model first become good enough?" That moment is what convergence time measures.

A training epoch is one complete pass through the training set. If a model trains for 20 epochs, it has had 20 full opportunities to adjust using the available examples. During those epochs, two measurements are especially useful. Training loss measures how far the model's current outputs are from the desired outputs, so a lower loss means the model's predictions fit the training examples better. Training accuracy measures the fraction of examples the model classifies correctly, so a higher accuracy means the model is making more correct decisions. A loss curve plots loss against epochs, and a learning curve often plots accuracy against epochs. Both curves turn a sequence of training measurements into a visible story of learning.

Convergence time uses those measurements to locate the earliest useful moment. Choose a target accuracy, such as 90%, 95%, or any threshold required by the experiment. Then watch the training accuracy after each epoch and find the first epoch where the model reaches that target. The metric is written as
$$
T_{\text{conv}} = \min \{t : A(t) \geq A_{\text{target}}\}
$$
Here, $T_{\text{conv}}$ is the convergence time, measured in epochs. The symbol $t$ is an epoch number. The expression $A(t)$ means the model's training accuracy at epoch $t$. The value $A_{\text{target}}$ is the target accuracy the model must reach. The word $\min$ means "take the smallest one," so the formula asks for the earliest epoch whose accuracy is at least the target. If a surrogate-gradient SNN reaches 90% accuracy at epoch 12 and stays above it afterward, then its convergence time for a 90% target is 12 epochs. If an STDP-based SNN reaches the same target at epoch 19, then it has a longer convergence time for that target.

This metric follows from measurable counts rather than a vague impression of speed. The epoch number is counted directly. The accuracy at each epoch is measured directly. The target accuracy is chosen before interpreting the run. Once those inputs are fixed, the convergence time is determined by the first crossing of the target line. A beginner confusion often comes from treating convergence as the final accuracy after training ends. Convergence time answers a different question: when did the model first become good enough under the chosen target? A model can eventually reach a strong final accuracy and still converge slowly if it takes many epochs to get there.

**Question.** If two SNNs both reach 92% accuracy by epoch 20, do they have the same convergence time?

**Answer.** Only if they first reached the chosen target accuracy at the same epoch. If the target is 90%, one model might cross it at epoch 10 while the other crosses it at epoch 18. Their final accuracy at epoch 20 can match, but their convergence times differ because convergence time depends on the first target crossing.

Training loss gives a second view of the same learning process. Loss is useful because it can show progress before accuracy visibly changes. A model may still classify some examples incorrectly while its output scores are moving in the right direction, so the loss can decline smoothly even when accuracy rises in steps. The important pattern is the rate of decrease. A faster loss decrease means the model is shaping its internal spiking behavior toward the task more quickly. Surrogate-gradient training is designed to use gradient-based updates even though spikes are discrete events, so its loss drops rapidly and stabilizes earlier. Converted SNNs begin from a trained conventional network and translate activations into spike-based behavior, so they can perform competitively but may need longer simulation behavior to approximate the original activation patterns. STDP-based training changes connections using spike timing relationships, so its learning can be efficient in spike use while its loss tends to settle more slowly and at a higher value.

The loss graph makes this comparison easier to see because it turns the table into curves. A steep downward curve means each epoch is buying a large improvement. A flatter curve means additional epochs are producing smaller gains. When a curve begins to level out, the model is stabilizing: the training process is still running, but the measured loss is changing less from one epoch to the next.

The surrogate-gradient curve falls more quickly than the other SNN curves, which indicates faster optimization during training. Its behavior supports the idea that convergence time is not only about the final endpoint; it is about the route taken to get there. The STDP-based curve changes more gradually and plateaus at a higher loss value, so it needs more epochs to settle into its available performance level. The converted SNN curve sits between these behaviors: it benefits from conversion but still carries the training dynamics of representing continuous activations through spike activity.

Accuracy curves complete the picture because convergence time is defined by reaching a target accuracy. A loss curve can suggest that a model is learning quickly, but the convergence formula needs $A(t)$, the measured accuracy at each epoch. The surrogate-gradient SNN reaches strong accuracy quickly and converges by around the 20th epoch. That means its accuracy curve has reached the relevant target level within the measured training window and has stabilized enough to be treated as useful for that target. Converted SNNs also improve across epochs, but their curve reflects a different path because the model must express learned activations through spike-based simulation. STDP-based SNNs rise more slowly, matching the slower loss behavior seen earlier. When the target accuracy is high, a slower-rising accuracy curve produces a longer convergence time because the first crossing happens later.

Convergence time moves only when its inputs move. If the target accuracy is raised, the same training run can have a later convergence time because the curve must climb farther before it qualifies. If the target accuracy is lowered, convergence time can become earlier because the model reaches that easier threshold sooner. If the measured accuracy values change because the training method improves, the first crossing may move earlier. If the epoch measurements and the target stay the same, the convergence time stays the same. This makes the metric stable and interpretable: it is a direct consequence of a target line and a measured learning curve.

**Question.** Why can a model with lower loss still fail to have the shortest convergence time?

**Answer.** Convergence time is defined using target accuracy, not loss. Lower loss usually suggests better learning progress, but the metric asks when $A(t)$ first reaches $A_{\text{target}}$. If the loss improves while accuracy remains below the target, convergence has not occurred for that target. Loss helps explain the training behavior; accuracy determines the convergence-time value.

A useful mental model is to picture training as a climb toward a performance threshold. The epoch count is the horizontal distance traveled. The learning curve shows height gained in accuracy. The target accuracy is a horizontal finish line. Convergence time is the first step where the model reaches that line. Loss curves explain how smoothly and quickly the model is reducing its errors during the climb, while accuracy curves decide when the model becomes useful under the chosen standard. For the SNN methods compared here, surrogate-gradient training reaches that useful region quickly, converted SNNs follow a competitive but different path, and STDP-based SNNs improve more gradually. The metric turns those curve shapes into a single question with a precise answer: how many epochs did this spiking model need before it was good enough?
