## Surrogate-Gradient Training

A spiking neuron accumulates incoming signals in its membrane potential and emits a spike when that potential reaches a threshold. Earlier, this threshold operation created a sharp transition: a value slightly below the threshold produces no spike, while a value slightly above it produces a spike. That discrete decision gives a spiking neural network its event-driven behavior, yet the same decision creates a difficulty during training. Gradient-based learning needs to estimate how a small change in a weight would change the network's output. At the threshold, an arbitrarily small change can switch the output abruptly from silence to a spike, so the ordinary derivative needed for backpropagation is unavailable there.

Consider a neuron whose membrane potential is extremely close to its firing threshold. Increasing one incoming weight may push the potential across the threshold and create a spike. Decreasing the same weight may keep the neuron silent. The spike operation therefore behaves like a step: its output remains fixed over most input values and jumps at one exact boundary. Away from the boundary, its derivative is zero because small changes produce no immediate change in the binary output. At the boundary, the jump makes the derivative undefined. If these values are used directly during backpropagation, the learning signal either disappears or cannot pass through the spike operation.

A surrogate gradient provides a practical route through this obstacle. The word *surrogate* means a substitute used for a particular purpose. During learning, the network uses a smooth gradient as a substitute for the unavailable derivative of the spike operation. This substitute gives nearby membrane potentials a meaningful measure of sensitivity: a neuron close to its threshold receives a stronger learning signal than one far from its threshold.

The training process can be understood as two coordinated passes through the same network. During the **forward pass**, the spiking neuron follows its actual threshold rule. It emits a discrete spike when its membrane potential reaches the threshold and remains silent otherwise. The resulting spikes travel through the network over time, preserving the event-based computation that defines an SNN. The network then produces an output, and a loss measures how far that output is from the desired result.

During the **backward pass**, training traces the loss back through the operations that produced it. Differentiable operations contribute their ordinary derivatives. When the backward calculation reaches a spike operation, it uses the surrogate gradient. The approximation allows a gradient signal to continue through the threshold and reach the earlier membrane potentials and synaptic weights.

Suppose a neuron sits just below threshold during the forward pass and therefore emits no spike. If the desired output would have been improved by that neuron firing, the backward pass can assign a useful gradient to the weights that influenced its membrane potential. Those weights can then be adjusted so that a similar input pushes the neuron slightly higher on the next training attempt. A neuron that fired when silence would have been more helpful can receive an adjustment in the opposite direction. In both cases, the surrogate gradient connects an output error to the continuous quantities that determine when spikes occur.

The approximation can be represented conceptually by writing the spike as
$$
S = H(u-\theta)
$$
Where $s$ is the binary spike output, $u$ is the neuron's membrane potential, $\theta$ is its firing threshold, and $H$ is the abrupt threshold operation. This expression computes whether the neuron fires: $s$ changes from $0$ to $1$ when $u$ reaches $\theta$.

Backpropagation would normally require the derivative of $s$ with respect to $u$. Surrogate-gradient training replaces that troublesome derivative during the backward pass:
$$
\frac{\partial s}{\partial u} \approx g(u-\theta)
$$
Where $\partial s/\partial u$ expresses how sensitive the spike output is to the membrane potential, and $g$ is a smooth approximation centered around the threshold. The quantity $u-\theta$ measures the neuron's distance from firing. This approximation lets training compute how changes in membrane potential-and ultimately changes in incoming weights-could affect the loss. The exact forward spike remains binary; the approximation supplies only the backward learning signal.

An analogy is a doorway controlled by a strict height sensor. The door opens only when the measured height reaches a fixed cutoff, giving an abrupt open-or-closed result. A technician adjusting the sensor still needs to know how close each measurement was to the cutoff. Replacing the door's real behavior would change the system, but using a smooth "closeness to the cutoff" scale during calibration gives the technician useful guidance. In an SNN, the threshold controls real spikes while the surrogate gradient provides this calibration signal during learning.

Repeated forward and backward passes gradually adjust the network's weights. Each forward pass generates spike events from the current membrane-potential dynamics. Each backward pass estimates which weight changes would reduce the loss, carrying gradients through spike operations with the smooth substitute. An optimizer then applies those changes, and the cycle continues over training examples. Because the weights are learned while the network itself performs spiking computation, this approach is called **direct SNN training**. The network learns its spiking patterns end to end rather than receiving parameters produced by first training a separate continuous-valued network and then converting it.

**Question.** If the backward pass uses a smooth approximation, does the neuron emit partial spikes during training?

**Answer.** The neuron emits discrete spikes during the forward pass: each spike value is binary. Smooth values appear only in the backward calculation, where they describe how strongly the loss should influence membrane potentials near the threshold. The approximation guides weight updates without changing the spike events used to compute the network's output.

**Question.** Why should a neuron near the threshold receive more gradient information than one far from it?

**Answer.** A small change in an incoming weight can readily move a near-threshold neuron across its firing boundary, changing whether it emits a spike. The same small change is less likely to alter the immediate firing decision of a neuron whose membrane potential is far from threshold. A surrogate gradient captures this local sensitivity and directs learning toward changes capable of affecting spike generation.

The resulting mental model has two layers that work together. The forward computation is a sequence of real, discrete spike decisions produced by membrane potentials crossing thresholds. The backward computation places a smooth bridge over each abrupt decision so that an error can flow toward the weights responsible for it. Surrogate-gradient training preserves spikes as the network's language of computation while giving gradient-based optimization enough information to shape when those spikes occur.
