## Classification Accuracy

Once each input has a predicted label and an expected label, evaluation begins with a simple comparison: did the two labels match? Imagine an SNN classifying a sequence of gestures. For every gesture, the network produces one predicted class, while the evaluation set provides the expected class. A prediction counts as **correct** when those two labels are the same. Classification accuracy combines all these individual comparisons into one number that describes how often the model gives the expected answer.

Suppose the expected labels for five inputs are:

- wave, clap, wave, point, clap

And the predicted labels are:

- wave, point, wave, point, clap

Compare the labels position by position. The predictions for the first, third, fourth, and fifth inputs match their expected labels, giving four correct predictions. The second prediction differs from its expected label, giving one incorrect prediction. Accuracy turns this record into a ratio by comparing the number of correct predictions with the total number of evaluated predictions.

Let $C$ represent the number of correct predictions and $N$ represent the total number of predictions. Each evaluated input contributes exactly one prediction to $N$, and each matching prediction contributes one to $C$. The **classification accuracy**, written as $A$, is therefore
$$
A = \frac{C}{N}
$$
Here, $A$ is the classification accuracy, $C$ is the number of predictions that match their expected labels, and $N$ is the total number of evaluated predictions. This formula computes the fraction of evaluated cases classified correctly. Multiplying that fraction by $100\%$ expresses the same result as a percentage:
$$
A_{\%} = \frac{C}{N}\times 100\%
$$
In the five-gesture example, $C=4$ and $N=5$, so
$$
A = \frac{4}{5}=0.8
$$
Which is equivalent to
$$
A_{\%}=0.8\times 100\%=80\%
$$
An accuracy of $80\%$ means that 80 out of every 100 predictions would be correct if the same proportion continued across a larger collection of comparable examples. For the actual five examples, it means exactly four predictions were correct. The percentage provides a convenient scale for comparison, while the underlying counts reveal how much evidence produced that percentage.

The denominator deserves careful attention. Accuracy depends on the set of predictions included in $N$. A result calculated from ten examples and a result calculated from ten thousand examples can have the same percentage, even though the larger evaluation contains much more evidence about the model's behavior. Accuracy should therefore be read together with a clear understanding of which evaluation cases were counted.

**Question.** If an SNN makes 72 correct predictions on 90 evaluated inputs, what is its classification accuracy?

**Answer.** The number of correct predictions is $C=72$, and the total number of predictions is $N=90$. Substituting these values gives
$$
A=\frac{72}{90}=0.8
$$
Multiplying by $100\%$ gives an accuracy of $80\%$. The result says that the predicted label matched the expected label for 80% of the evaluated inputs.

Accuracy is especially useful when a comparison asks how reliably different models assign the expected classes. Every correct prediction contributes equally to the numerator, so the ratio offers a compact view of classification success. A higher value means that a larger fraction of evaluated predictions matched their expected labels under the chosen evaluation conditions.

An SNN comparison usually involves several evaluation dimensions, however, because two models with similar accuracy can behave very differently while producing their predictions. One model may respond with lower inference latency, meaning less time passes before it produces a classification. Another may generate fewer spikes per inference, using sparser activity to reach its decision. Models may also differ in energy consumption, responsiveness to event-driven inputs, training convergence, and the consistency of results across independent runs. Accuracy leaves each of these properties unresolved because its calculation uses only matches and the total prediction count.

Consider two SNNs that each classify 90 of 100 inputs correctly. Both have an accuracy of $90\%$. If one model reaches each prediction sooner while the other requires more inference time, the accuracy values remain equal. If one generates far fewer spikes, the formula still returns the same value because spike count never enters $C/N$. If their training curves reach the final accuracy at different rates, the final correct-prediction ratio also hides that difference. Accuracy describes the outcome of classification, while the other measurements describe the computational path and resources associated with that outcome.

A common beginner confusion is to treat a small accuracy difference as a complete ranking of two models. A careful comparison instead asks what operating goal the model must satisfy. A system intended for responsive event-driven processing may need a useful balance among correct predictions, latency, spike activity, and energy use. A model intended to learn efficiently may also be judged by how quickly and consistently its accuracy stabilizes during training. Classification accuracy remains one evaluation dimension within that broader picture.

**Question.** If two SNNs both achieve $95\%$ accuracy, are they equivalent?

**Answer.** They produce the same proportion of correct predictions on the stated evaluations. Their latency, energy consumption, spike count, responsiveness, convergence behavior, and variation across runs may still differ. The shared accuracy establishes one point of similarity; the remaining measurements determine how each model reaches that classification performance and whether its behavior fits the intended use.

The most useful mental model is a scoreboard built from label matches. Each input places one prediction on the board, every match increases the correct count, and dividing that count by all evaluated predictions produces accuracy. The scoreboard answers, "How often was the expected class selected?" A complete SNN comparison then places that answer beside measurements of timing, activity, resource use, and learning behavior, allowing classification success to be understood as one part of the model's overall performance.
