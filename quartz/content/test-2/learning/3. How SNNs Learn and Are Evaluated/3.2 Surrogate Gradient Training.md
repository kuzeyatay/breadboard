## Surrogate Gradient Training

A spiking neuron can gather evidence gradually, then release that evidence as a sudden spike when its internal voltage crosses a threshold. That threshold gives SNNs their event-based character: silence can mean "nothing worth sending," and a spike can mean "enough evidence has arrived now." The same threshold also creates the learning problem. During training, a network needs to adjust its weights by asking a small question many times: "If this weight changed a little, would the final answer improve?" For a smooth value, that question has a usable answer. For a spike, the answer is awkward, because the output jumps from no spike to spike at the threshold.

Imagine training a gesture-recognition system on an event camera. Most pixels stay quiet most of the time, and only changes in the scene create events. A spiking network is a natural fit because it can process those events as timed spikes instead of repeatedly processing full image frames. During learning, however, the network must discover which incoming spikes should push later neurons closer to firing and which should have little effect. If every spike decision behaves like a hard switch, then a tiny weight change usually appears to do nothing, until it suddenly changes the spike time or creates a spike. A gradient-based optimizer depends on gradual feedback, so this hard switch makes direct learning unstable or uninformative.

A surrogate gradient solves this by keeping the forward behavior spiking while making the learning signal easier to use. In the forward pass, the neuron still emits a discrete spike when its voltage crosses threshold. During the weight update, the training rule uses a smooth stand-in for the spike's otherwise abrupt change. The word "surrogate" means substitute: the network uses a substitute slope for learning, while preserving spike events for computation. This lets the optimizer estimate how a weight should move even when the actual spike function gives almost no useful slope.

The learning rule can be understood through the basic gradient update:
$$
W_{\text{new}} = w_{\text{old}} - \eta \, \tilde{g}
$$
Here, $w_{\text{old}}$ is the current synaptic weight, $w_{\text{new}}$ is the adjusted weight after one update, $\eta$ is the learning rate that controls the size of the step, and $\tilde{g}$ is the surrogate gradient, the substitute estimate of how changing that weight affects the training error. If $\tilde{g}$ is positive, increasing the weight would raise the error, so the rule lowers the weight. If $\tilde{g}$ is negative, increasing the weight would reduce the error, so subtracting a negative value raises the weight. The formula lets the network turn many small credit-assignment signals into systematic weight changes.

A concrete way to picture this is to imagine a neuron that almost fired for the correct class but stayed just below threshold. A hard spike rule would report the same output as a neuron far below threshold: no spike. The surrogate gradient gives the near-threshold neuron a stronger learning signal because a small weight change could plausibly make it fire at the useful time. A neuron far from threshold receives a weaker adjustment because a tiny change would probably leave its behavior unchanged. The training process therefore treats "almost enough evidence" differently from "nowhere near enough evidence," which is exactly the distinction a learner needs.

**Question.** If the network still uses real spikes during the forward pass, where does the "soft" part of surrogate gradient training appear?

**Answer.** The soft part appears in the training signal used to adjust weights. The neuron still sends a discrete spike when its voltage crosses threshold, so inference remains event-based. During learning, the abrupt spike decision is paired with a smooth substitute slope so the optimizer can estimate whether each weight should increase or decrease.

This training style is associated with high accuracy because it trains the spiking network directly for the task instead of only copying another model's behavior after the fact. A conventional ANN can achieve strong accuracy with continuous activations, but those continuous activations do not automatically translate into short spike sequences. ANN-to-SNN conversion can preserve much of the accuracy, yet it often needs longer simulation windows and more spikes to approximate the original activation values. Surrogate gradient training pushes the spiking network itself to produce useful spike patterns, so accuracy can approach ANN performance while keeping the representation native to spikes. In the reported comparison, surrogate-gradient-trained SNNs closely approximate ANN accuracy within about 1-2%.

Latency enters through time. A spiking network does not merely decide what to output; it decides when enough evidence has arrived to output it. If a model needs a long window of spikes before its rates become reliable, then inference becomes slower. Converted SNNs can face this issue because rate-coded spike propagation may require more time steps to approximate continuous ANN activations. Surrogate-trained SNNs learn patterns that can become discriminative earlier, so they are associated with low-latency responses around 10 ms. On event-based datasets and neuromorphic platforms, SNN inference can fall in the 5-10 ms range per sample, while CNN-based ANN inference is described in a higher 20-50 ms range depending on model and hardware.

The same training choice also affects spike count and energy. Each spike is a useful event, but a large number of spikes means more communication and computation. Surrogate gradient SNNs are described as using about 15 mJ per inference and around 12,000 spikes, compared with about 20 mJ and 20,000 spikes for converted SNNs. STDP-based SNNs can go even lower, around 5 mJ and 4,000 spikes, while accepting slightly reduced accuracy and slower convergence behavior. Surrogate training therefore sits in a practical middle region: it keeps accuracy close to ANN levels, lowers latency, and reduces energy and spike count compared with heavier converted spike activity.

Training convergence describes how quickly learning settles into a useful performance range. If a network needs many training epochs before accuracy becomes reliable, it costs more time and compute to prepare the model. Surrogate-gradient-trained SNNs are associated with faster convergence by the 20th epoch. That tells you the substitute learning signal is doing useful work: it gives the optimizer enough direction to improve the spike-producing weights within a relatively short training horizon. The phrase "convergence by the 20th epoch" means that, across repeated passes through the training data, the model's learning behavior has largely reached its effective level by that point.

**Question.** Why can surrogate gradient training improve both accuracy and latency instead of improving only one metric?

**Answer.** It trains the spiking network to make task-relevant spike decisions directly. The same learned weights that improve classification can also make useful spikes appear earlier in the simulation window. Earlier useful spikes reduce the time needed for inference, while direct gradient-based optimization helps keep accuracy close to ANN performance.

The mental model is a hard spiking machine guided by a soft training signal. The hard part gives SNNs their event-based computation: neurons stay quiet until accumulated evidence crosses a threshold, then they communicate with spikes. The soft part gives learning a usable direction: near-threshold situations receive informative weight updates instead of being treated as invisible jumps. As training repeats, weights become tuned so the right neurons spike at useful times, with fewer wasted events and shorter decision windows. That is why surrogate gradient training is linked with near-ANN accuracy, convergence within about 20 epochs, and low-latency SNN inference around 10 ms.
