## Measuring Sparse Neural Activity

A spike train records when a neuron emits discrete events, and event-driven computation uses those events to decide when work is needed. Once activity is represented this way, a practical question appears: how active is an entire layer over a complete batch and simulation period? Looking at a raster of spikes can give an immediate visual impression, but impressions become unreliable when experiments contain different numbers of samples, timesteps, or neurons. A layer with 1,000 recorded events may be highly active in a small experiment and extremely sparse in a much larger one. A fair measurement therefore needs to compare observed activity with the total number of opportunities for activity.

Imagine running a layer containing $N$ neurons. During each timestep, every neuron occupies one of two event states: active if it emits a spike and silent if it does not. If the simulation lasts for $T$ timesteps, each neuron has $T$ opportunities to become active. The layer therefore contains $TN$ neuron-time positions for one input sample. Processing a batch of $B$ samples expands the total to $BTN$ positions.

The **active-neuron count**, written as $a$, counts the active positions across all three dimensions: batch sample, timestep, and neuron. One neuron firing during three timesteps contributes three active positions. Three neurons each firing once also contribute three. This counting rule treats activity as a collection of discrete events distributed through space and time, matching the event-driven operation of a spiking network.

Raw counts alone depend heavily on experimental scale. Suppose one run records $500$ active positions and another records $1{,}000$. The second count sounds denser until the available positions are considered. If the first run contains $1{,}000$ possible positions, its activity occupies half of them. If the second contains $100{,}000$, its activity occupies only one hundredth of them. Normalization turns these scale-dependent counts into comparable fractions.

The normalized neural activity is
$$
A=\frac{100a}{BTN}
$$
Here, $A$ is the layer activity expressed as a percentage, $a$ is the number of active neuron-time positions, $B$ is the batch size, $T$ is the total number of timesteps, and $N$ is the number of neurons in the layer. The product $BTN$ gives the total number of possible positions in which a neuron could be active. Dividing $a$ by that product computes the active fraction, while multiplying by $100$ converts the fraction into a percentage.

Consider a batch of $B=2$ samples processed for $T=5$ timesteps by a layer with $N=100$ neurons. The layer has
$$
BTN=2\times5\times100=1{,}000
$$
Possible neuron-time positions. If $a=80$ of those positions contain spikes, then
$$
A=\frac{100\times80}{1{,}000}=8\%
$$
An activity value of $8\%$ means that spikes occupy 8 out of every 100 available positions on average. The remaining $92\%$ are silent positions. In an event-driven computation, that pattern describes a stream in which events are relatively rare and silence dominates.

This percentage also provides a precise way to discuss **activity sparsity**. Sparsity grows as the active fraction falls: fewer positions contain events, and more positions remain silent. If the example produced $200$ active positions under the same dimensions, its activity would rise to $20\%$, leaving $80\%$ silent. If it produced only $10$, activity would fall to $1\%$, leaving $99\%$ silent. The activity percentage and the silent percentage therefore fit together as
$$
\text{silent percentage}=100\%-A
$$
The two values describe complementary portions of the same set of possible neuron-time positions. Lower normalized activity indicates a sparser event pattern, while higher normalized activity indicates a denser one.

**Question.** If the batch size doubles while the firing pattern per sample stays the same, should normalized activity double?

**Answer.** The active count $a$ doubles because the larger batch contains twice as many samples and therefore twice as many events under the same per-sample pattern. The denominator $BTN$ also doubles because $B$ doubles. These changes cancel in the ratio, so $A$ remains unchanged. This stability is the purpose of batch normalization in the metric: the percentage describes the typical fraction of active positions rather than the total number collected.

Time requires the same care. A simulation running for more timesteps naturally offers more opportunities to spike. Suppose a layer of $100$ neurons processes one sample for $10$ timesteps and produces $50$ active positions. Its activity is $5\%$. Extending the simulation to $20$ timesteps while preserving the same average event rate would produce about $100$ active positions. Although the raw count doubles, the denominator doubles as well, leaving activity at $5\%$. The metric separates duration from density.

Layer size follows the same logic. A count of $100$ active positions fills a substantial portion of a layer with $20$ neurons observed for a few timesteps, yet occupies a much smaller portion of a layer with $2{,}000$ neurons under the same batch and duration. Including $N$ allows activity percentages from differently sized layers to express the fraction of their own available positions that became active.

**Question.** Does an activity value of $5\%$ mean that exactly $5\%$ of the neurons fired?

**Answer.** It means that $5\%$ of all neuron-time positions across the batch were active. The events could come from many neurons firing occasionally or from a smaller group firing repeatedly. The metric measures overall event density across batch, time, and layer dimensions; it does not identify how those events are distributed among individual neurons.

Normalized neural activity can therefore be understood as a filling fraction for an event grid. Batch samples form one dimension, timesteps form another, and neurons form the third. Every spike fills one position in that grid. The active count tells how many positions are filled, the product $BTN$ tells how many positions exist, and $A$ reports the filled percentage. Through this mental model, event-driven sparsity becomes measurable: sparse activity is a mostly empty grid carrying information through a comparatively small number of precisely located events.
