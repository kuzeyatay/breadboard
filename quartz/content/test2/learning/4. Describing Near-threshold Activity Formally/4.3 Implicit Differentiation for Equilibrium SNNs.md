## Implicit Differentiation for Equilibrium SNNs

Temporal credit assignment asks how a change in a synaptic parameter eventually changes the network's objective after recurrent activity has propagated. Imagine repeatedly updating a feedback spiking network with the same input. Early updates may vary as spikes alter later activity through recurrent connections, yet the network can eventually settle into a stable pattern. Once that settled pattern is reached, its defining mathematical property provides a direct route from the objective back to the parameters.

<!-- learning-unit:U16:after-introduction -->

Let $a$ represent the network state and let $f_\theta(a)$ represent one recurrent update of that state. The parameter collection $\theta$ contains the trainable quantities, such as synaptic weights. An **equilibrium state**, written $a^*$, is a state that remains unchanged by another update:
$$
A^* = f_\theta(a^*)
$$
The star marks the settled value. The function $f_\theta$ depends on both the current state and the parameters, so changing $\theta$ can move the equilibrium. Training requires measuring that movement: if a parameter changes slightly, how does $a^*$ change, and how does that change affect the objective?

A concrete scalar example makes the fixed-point relation easier to see. Suppose a simplified recurrent state obeys
$$
F_\theta(a)=\theta a+b
$$
Where $a$ is a single activity value, $\theta$ controls feedback strength, and $b$ is a fixed input contribution. At equilibrium,
$$
A^*=\theta a^*+b
$$
Collecting the terms containing $a^*$ gives
$$
(1-\theta)a^*=b
$$
So
$$
A^*=\frac{b}{1-\theta}
$$
The equilibrium therefore depends on $\theta$, even though $a^*$ appears on both sides of its defining equation. A stronger feedback parameter changes the settled activity because every recurrent update feeds more of the current state back into the network.

For a full network, $a^*$ is a vector rather than a single number. Differentiating the fixed-point equation with respect to $\theta$ gives
$$
\frac{d a^*}{d\theta}
=
\frac{\partial f_\theta(a^*)}{\partial a^*}
\frac{d a^*}{d\theta}
+
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
Here, $\frac{d a^*}{d\theta}$ is the equilibrium-state gradient with respect to the parameters. The matrix $\frac{\partial f_\theta(a^*)}{\partial a^*}$ measures how a small change in the equilibrium state changes one recurrent update. The term $\frac{\partial f_\theta(a^*)}{\partial\theta}$ measures how a parameter change directly changes that update while the state is held fixed.

The unknown $\frac{d a^*}{d\theta}$ appears on both sides. Moving its recurrent contribution to the left produces
$$
\left(
I-\frac{\partial f_\theta(a^*)}{\partial a^*}
\right)
\frac{d a^*}{d\theta}
=
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
Where $I$ is the identity matrix. This equation lets us compute how the settled state responds to parameter changes by solving a linear system at equilibrium.

When the matrix is invertible, the relation can be written as
$$
\frac{d a^*}{d\theta}
=
\left(
I-\frac{\partial f_\theta(a^*)}{\partial a^*}
\right)^{-1}
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
The inverse captures the accumulated effect of feedback. In the scalar example, $\frac{\partial f_\theta}{\partial a}=\theta$ and $\frac{\partial f_\theta}{\partial\theta}=a^*$, so
$$
\frac{d a^*}{d\theta}
=
\frac{a^*}{1-\theta}
=
\frac{b}{(1-\theta)^2}
$$
This agrees with directly differentiating $a^*=b/(1-\theta)$. The factor $1/(1-\theta)$ expresses how recurrence amplifies a direct parameter effect before the network settles again.

Training usually begins with an objective $L(a^*)$, a scalar that evaluates the equilibrium activity. The chain rule gives
$$
\frac{\partial L(a^*)}{\partial\theta}
=
\frac{\partial L(a^*)}{\partial a^*}
\frac{d a^*}{d\theta}
$$
The row vector $\frac{\partial L}{\partial a^*}$ measures how the objective changes when each component of the equilibrium state changes. Substituting the equilibrium-state gradient yields the parameter gradient.

A compact form follows by defining the equilibrium residual
$$
G_\theta(a)=f_\theta(a)-a
$$
At equilibrium, $g_\theta(a^*)=0$. Its state Jacobian is
$$
J_g(a^*)=
\frac{\partial g_\theta(a^*)}{\partial a^*}
=
\frac{\partial f_\theta(a^*)}{\partial a^*}-I
$$
Because $J_g=-(I-\partial f_\theta/\partial a^*)$, the objective gradient becomes
$$
\frac{\partial L(a^*)}{\partial\theta}
=
-
\frac{\partial L(a^*)}{\partial a^*}
\left(J_g(a^*)\right)^{-1}
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
Every factor has a specific role: $\frac{\partial L}{\partial a^*}$ translates state changes into objective changes, $J_g^{-1}$ accounts for recurrent feedback around the equilibrium, and $\frac{\partial f_\theta}{\partial\theta}$ translates parameter changes into direct changes of the network update.

In practice, the inverse Jacobian can be handled through an equivalent linear system. Define a vector $x$ by
$$
J_g(a^*)^{T}x+
\left(\frac{\partial L(a^*)}{\partial a^*}\right)^{T}
=0
$$
After solving for $x$, the parameter gradient is
$$
\frac{\partial L(a^*)}{\partial\theta}
=
X^{T}
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
This calculation uses the fixed-point condition as a compressed description of the recurrent computation. The forward dynamics establish $a^*$; the backward calculation asks how that equilibrium must shift to remain a fixed point after $\theta$ changes.

**Question.** Why does the equilibrium gradient contain an inverse Jacobian?

**Answer.** A parameter change directly perturbs one network update, while feedback causes that perturbation to influence the state again through recurrent connections. The matrix $I-\frac{\partial f_\theta}{\partial a^*}$ couples all required state adjustments. Solving the corresponding linear system finds the combined adjustment that restores the fixed-point relation.

**Question.** Does reaching the same state after one additional update guarantee a useful equilibrium gradient?

**Answer.** The fixed-point equality establishes the equilibrium relation, while differentiation also requires the associated Jacobian system to be solvable. When the relevant matrix is invertible, a small parameter change corresponds locally to a well-defined change in $a^*$, allowing the objective gradient to be computed.

The resulting mental model has three linked parts: recurrent dynamics settle into $a^*$, the equation $a^*=f_\theta(a^*)$ constrains how that state can move, and implicit differentiation converts that constraint into a parameter gradient. The equilibrium acts as a mathematical summary of the feedback network's settled computation, while the Jacobian describes how sensitive that summary is to small changes.
