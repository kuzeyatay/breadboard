## Finite-Difference Gradient Approximation

A surrogate gradient provides one way to carry learning signals through the abrupt threshold that produces a spike. Finite differences approach the same obstacle from another direction: instead of asking for the derivative of the spike operation itself, they measure how the final loss changes when the network parameters are nudged. Imagine turning one synaptic weight slightly upward, running the spiking network over the same input sequence, and observing whether the loss rises or falls. That measured change reveals which direction would improve the parameter.

Let the network's trainable parameters include all adjustable synaptic weights. Although these weights may originally live in separate matrices for different layers, they can be arranged into one long parameter vector,
$$
\boldsymbol{\theta}
=
[\theta_1,\theta_2,\ldots,\theta_P]^\top
$$
Where $\boldsymbol{\theta}$ is the complete parameter vector, $\theta_i$ is its $i$-th scalar parameter, $P$ is the total number of trainable parameters, and ${}^\top$ indicates that the entries are written as a column. Arranging the weights this way is called **flattening**. Flattening changes only how the parameters are listed for the calculation; the network still uses each weight in its original connection when it processes spikes.

The network's behavior over time produces a loss,
$$
L(\boldsymbol{\theta})
$$
Where $L$ is the loss function and $\boldsymbol{\theta}$ specifies the weights used during the temporal simulation. The loss compresses the quality of the resulting spike-based prediction into a number that training can reduce. Because a membrane potential carries information from one timestep to later timesteps, changing a weight can alter an early voltage, a later threshold crossing, the subsequent spike train, and eventually the loss. Evaluating $L(\boldsymbol{\theta})$ therefore captures the full temporal consequence of the chosen parameters.

To estimate the effect of one parameter, choose a small positive perturbation scale $\varepsilon$. Then construct two nearby versions of the parameter vector. One increases $\theta_i$ by $\varepsilon$, while the other decreases it by $\varepsilon$. A convenient vector for expressing these changes is $\mathbf{e}_i$, whose $i$-th entry is $1$ and whose remaining entries are $0$. The two perturbed parameter vectors are
$$
\boldsymbol{\theta}^{+}
=
\boldsymbol{\theta}+\varepsilon\mathbf{e}_i
\qquad\text{and}\qquad
\boldsymbol{\theta}^{-}
=
\boldsymbol{\theta}-\varepsilon\mathbf{e}_i
$$
Running the network with each vector gives two losses, $L(\boldsymbol{\theta}^{+})$ and $L(\boldsymbol{\theta}^{-})$. Their difference measures how the loss responds around the current value of $\theta_i$. Dividing that loss difference by the total distance $2\varepsilon$ gives the central finite-difference estimate
$$
\frac{\partial L}{\partial \theta_i}
\approx
\frac{
L(\boldsymbol{\theta}+\varepsilon\mathbf{e}_i)
-
L(\boldsymbol{\theta}-\varepsilon\mathbf{e}_i)
}{
2\varepsilon
}
$$
Here, $\frac{\partial L}{\partial \theta_i}$ is the estimated sensitivity of the loss to parameter $\theta_i$; $L$ is the loss after processing the relevant temporal input; $\boldsymbol{\theta}$ is the current flattened parameter vector; $\mathbf{e}_i$ selects the parameter being tested; and $\varepsilon$ sets the size of the controlled perturbation. The formula computes a slope from two nearby loss evaluations. A positive estimate means the loss tends to increase as $\theta_i$ increases, so reducing that parameter points toward a lower loss. A negative estimate means increasing the parameter points toward a lower loss.

For a concrete interpretation, suppose a weight currently equals $0.40$, and choose $\varepsilon=0.01$. Running the network with that weight set to $0.41$ produces a loss of $0.82$, while setting it to $0.39$ produces a loss of $0.78$. The estimate is
$$
\frac{\partial L}{\partial \theta_i}
\approx
\frac{0.82-0.78}{2(0.01)}
=
2
$$
Near the current weight, increasing the weight by one small unit of parameter change is associated with an increase in loss at an estimated local rate of $2$. A gradient-descent update would therefore move the weight downward. The calculation reaches this conclusion from complete network evaluations, including all membrane evolution and spike events caused by each perturbation.

The perturbation scale controls how locally the slope is measured. A smaller $\varepsilon$ compares parameter settings closer to the current network, while a larger $\varepsilon$ measures change across a wider interval. In a spiking network, an extremely small perturbation may leave every threshold decision unchanged, producing identical losses and an estimated gradient of zero. A wider perturbation may move a membrane potential across threshold, change a spike, and reveal a measurable loss difference. The chosen scale therefore determines which changes in the event-driven trajectory become visible to the estimate.

**Question.** How does this method avoid differentiating the spike threshold?

**Answer.** It treats the entire SNN simulation as a function that maps parameters to a loss. The network is run at nearby parameter settings, and the resulting loss values are compared. The calculation needs observable loss changes rather than a derivative of the binary spike with respect to membrane voltage.

Estimating one coordinate requires two perturbed loss evaluations. Estimating every component of a gradient with $P$ parameters therefore requires approximately $2P$ network evaluations for a central-difference calculation. Each evaluation must process the temporal sequence, so the estimation cost grows with both the number of parameters and the work required for one temporal simulation.

**Question.** Why flatten the weights if they belong to different layers?

**Answer.** Flattening gives every trainable scalar a unique coordinate, making it possible to perturb one weight at a time and place its estimated derivative into a single gradient vector. After estimation, each component still updates the corresponding weight in its original layer and connection.

The resulting mental model is a careful probing process: collect every trainable weight into $\boldsymbol{\theta}$, nudge one coordinate in both directions, replay the network's temporal dynamics, compare the two losses, and turn that change into a local slope. Repeating the probe across coordinates builds an estimated gradient from observed changes in behavior, allowing temporal credit to be assigned through the loss even when spike generation creates an abrupt threshold.
