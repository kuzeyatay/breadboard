## Implicit Differentiation at Equilibrium

Surrogate gradients make spike-based learning possible by providing usable local derivatives where hard spike generation would otherwise interrupt gradient calculations. A feedback spiking neural network adds another challenge: recurrent connections allow the current activity to influence later activity, which then feeds back again. Imagine presenting an input and allowing this feedback activity to settle. The network may pass through many intermediate states before reaching a stable pattern. Recording and revisiting every intermediate step can consume substantial memory and computation. Equilibrium-based training instead treats the settled state as the object to differentiate.

Let $a$ denote the network state, which can represent the activity variables used to describe the feedback network, and let $f_\theta$ denote one application of the network dynamics with parameters $\theta$. Applying the dynamics updates the state:
$$
A_{\text{new}} = f_\theta(a)
$$
An **equilibrium state** is a state that remains unchanged under this update. Writing it as $a^*$, the equilibrium condition is
$$
A^* = f_\theta(a^*)
$$
Here, $a^*$ is the settled network state, $f_\theta$ is the feedback SNN's state-update function, and $\theta$ collects trainable parameters such as synaptic weights. The equation says that feeding the settled activity back through the network reproduces the same activity.

Consider a simple interpretation. Suppose the state contains the steady firing activity of two interacting neuron groups. One group excites the other, and the second group feeds activity back to the first. Repeated updates gradually produce a pair of settled activity values. At equilibrium, another update returns that same pair. Training then asks a sensitivity question: if a parameter changes slightly, how does the settled pair $a^*$ move?

Because $a^*$ depends on $\theta$, both sides of the equilibrium equation change when $\theta$ changes. Differentiating
$$
A^* = f_\theta(a^*)
$$
With respect to $\theta$ gives
$$
\frac{d a^*}{d\theta}
=
\frac{\partial f_\theta(a^*)}{\partial a^*}
\frac{d a^*}{d\theta}
+
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
Every term has a specific role. The total derivative $\frac{d a^*}{d\theta}$ measures how the equilibrium state changes when the parameters change. The partial derivative $\frac{\partial f_\theta(a^*)}{\partial a^*}$ measures how one network update responds to a change in its input state while the parameters are held fixed. The partial derivative $\frac{\partial f_\theta(a^*)}{\partial\theta}$ measures how one update responds directly to a parameter change while the state is held fixed.

The product in the middle captures the feedback pathway. A parameter change moves the equilibrium state; that moved state enters the recurrent update; and the update produces an additional change. Gathering every occurrence of the equilibrium-state derivative on the left yields
$$
\left(
I-\frac{\partial f_\theta(a^*)}{\partial a^*}
\right)
\frac{d a^*}{d\theta}
=
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
The symbol $I$ is the identity matrix, which leaves a state unchanged when multiplied by it. The matrix
$$
I-\frac{\partial f_\theta(a^*)}{\partial a^*}
$$
Describes how the equilibrium constraint balances a direct state change against the change returned through feedback. Solving this equation gives the **fixed-point sensitivity** $\frac{d a^*}{d\theta}$: the parameter sensitivity of the settled state.

When the matrix has an inverse, the sensitivity can be written as
$$
\frac{d a^*}{d\theta}
=
\left(
I-\frac{\partial f_\theta(a^*)}{\partial a^*}
\right)^{-1}
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
This expression combines two effects. The rightmost derivative gives the immediate influence of the parameters on one update. The inverse matrix accounts for how feedback circulates and reshapes that influence at equilibrium. A useful analogy is a room with echoes. A clap creates a direct sound, while reflections repeatedly redistribute it. The inverse factor represents the accumulated effect of those reflections in the settled response.

The same result can be expressed by moving the equilibrium equation into a residual function:
$$
G_\theta(a)=f_\theta(a)-a
$$
At equilibrium,
$$
G_\theta(a^*)=0
$$
Let $J_g(a^*)$ denote the Jacobian of $g_\theta$ with respect to the state, evaluated at $a^*$. A Jacobian is a matrix containing the local derivatives of every output component with respect to every state component. Since $g_\theta(a)=f_\theta(a)-a$,
$$
J_g(a^*)
=
\frac{\partial f_\theta(a^*)}{\partial a^*}-I
$$
The equilibrium sensitivity therefore becomes
$$
\frac{d a^*}{d\theta}
=
-J_g(a^*)^{-1}
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
The minus sign follows from the chosen residual $g_\theta(a)=f_\theta(a)-a$. Choosing the reversed residual would move the sign into the Jacobian instead; the underlying sensitivity would remain the same.

Now let $L(a^*)$ be the objective evaluated at the equilibrium state. The derivative of the objective with respect to the parameters follows the chain rule:
$$
\frac{\partial L(a^*)}{\partial\theta}
=
\frac{\partial L(a^*)}{\partial a^*}
\frac{d a^*}{d\theta}
$$
Substituting the equilibrium sensitivity gives
$$
\frac{\partial L(a^*)}{\partial\theta}
=
-
\frac{\partial L(a^*)}{\partial a^*}
J_g(a^*)^{-1}
\frac{\partial f_\theta(a^*)}{\partial\theta}
$$
Here, $\frac{\partial L}{\partial a^*}$ measures how the objective responds to the settled activity, $J_g(a^*)^{-1}$ propagates that sensitivity through the equilibrium constraint, and $\frac{\partial f_\theta(a^*)}{\partial\theta}$ connects the resulting state sensitivity to the trainable parameters. Together, these factors compute the parameter gradient from the settled state and the local derivatives evaluated there.

In practice, the inverse notation expresses a linear-system solution. If a matrix $A$ and a quantity $b$ satisfy $Ax=b$, then $x=A^{-1}b$ whenever the inverse exists. The gradient calculation can therefore be organized around solving the corresponding linear system, avoiding the need to construct an explicit inverse matrix.

**Question.** Does the equilibrium state stop depending on the parameters because it no longer changes during state updates?

**Answer.** The equilibrium remains sensitive to the parameters. Its defining equality says that one state update leaves it unchanged for the current parameter values. Changing a synaptic parameter changes $f_\theta$, so the state satisfying $a^*=f_\theta(a^*)$ can also change. Implicit differentiation computes exactly that movement.

**Question.** Where did the intermediate feedback states go in this calculation?

**Answer.** Their accumulated influence is encoded in the equilibrium constraint and its Jacobian. The factor involving $J_g(a^*)^{-1}$ captures how a local disturbance is redistributed through recurrent feedback at the settled state. The resulting mental model is a chain from parameters, through the equilibrium condition, into the settled activity, and finally into the objective: implicit differentiation follows that chain directly at the fixed point.
