## Backpropagation Through Time

A discrete-time spiking neuron already carries its membrane state from one timestep into the next. If an input at time $1$ raises the membrane potential, some trace of that change may remain at time $2$, influence the state at time $3$, and eventually affect the loss measured after several updates. Training therefore has to follow the same temporal chain that produced the neuron's behavior. A weight used now can influence the current state directly, while the same weight's earlier uses can influence the current state through every intervening membrane update.

Let the neuron's state evolve according to
$$
U[t] = F\bigl(u[t-1], x[t]; W\bigr)
$$
Here, $t$ is the discrete timestep, $u[t]$ is the neuron state at that timestep, $u[t-1]$ is the state carried forward from the previous timestep, $x[t]$ is the current input, $W$ is a trainable weight or collection of weights, and $F$ is the state-update rule. The exact update can include integration, leakage, input current, and any other state behavior already built into the neuron model. For temporal-gradient reasoning, its essential feature is that $u[t]$ depends on both $W$ and $u[t-1]$.

Suppose training evaluates a loss $L[t]$ at each timestep. The total loss over a sequence of $T$ steps is
$$
L = \sum_{t=1}^{T} L[t]
$$
The symbol $L$ denotes the full sequence loss, $L[t]$ denotes the contribution evaluated at time $t$, and $T$ is the final timestep. Differentiating this sum gives
$$
\frac{dL}{dW}
=
\sum_{t=1}^{T}
\frac{dL[t]}{dW}
$$
This equation shows that the total loss gradient accumulates contributions across timesteps. Each term asks a concrete question: how did the shared weight $W$ affect the loss observed at time $t$? A three-step sequence, for example, produces three contributions,
$$
\frac{dL}{dW}
=
\frac{dL[1]}{dW}
+
\frac{dL[2]}{dW}
+
\frac{dL[3]}{dW}
$$
The three terms refer to one shared parameter. Temporal unrolling makes that repeated use easier to see by drawing the recurrent neuron as a chain of copies: one copy processes time $1$, another processes time $2$, and another processes time $3$. Each copy has its own state $u[t]$, while every copy uses the same $W$. The unrolled chain represents repeated computation through time rather than separate neurons with separate weights.

To understand one term in the loss gradient, assume $L[t]$ depends on the state $u[t]$. The chain rule gives
$$
\frac{dL[t]}{dW}
=
\frac{\partial L[t]}{\partial u[t]}
\frac{du[t]}{dW}
$$
The factor $\partial L[t]/\partial u[t]$ measures how sensitive the time-$t$ loss is to the time-$t$ state. The factor $du[t]/dW$ measures how sensitive that state is to the shared weight. Their product computes the influence of $W$ on $L[t]$ along the path through $u[t]$.

The state sensitivity contains two routes because the update $u[t]=F(u[t-1],x[t];W)$ uses $W$ directly and receives an earlier state that already depends on $W$. Applying the chain rule again gives
$$
\frac{du[t]}{dW}
=
\frac{\partial u[t]}{\partial W}
+
\frac{\partial u[t]}{\partial u[t-1]}
\frac{du[t-1]}{dW}
$$
The term $\partial u[t]/\partial W$ is the direct contribution from using $W$ during the current update. The factor $\partial u[t]/\partial u[t-1]$ measures how strongly the current state depends on the previous state. Multiplying it by $du[t-1]/dW$ carries every earlier influence of $W$ forward into the current timestep. This second route is the recurrent gradient path.

Consider the third timestep. Its state sensitivity expands as
$$
\frac{du[3]}{dW}
=
\frac{\partial u[3]}{\partial W}
+
\frac{\partial u[3]}{\partial u[2]}
\frac{\partial u[2]}{\partial W}
+
\frac{\partial u[3]}{\partial u[2]}
\frac{\partial u[2]}{\partial u[1]}
\frac{\partial u[1]}{\partial W}
$$
The first term represents the use of $W$ at time $3$. The second represents the use of $W$ at time $2$, followed by propagation from $u[2]$ to $u[3]$. The third represents the use of $W$ at time $1$, followed by propagation through both later state transitions. An early input can therefore affect a later training signal even when the loss is evaluated several updates after that input arrived.

**Question.** Why does the gradient include an earlier use of $W$ when the loss is measured at the current timestep?

**Answer.** The current state contains information carried from earlier states. Since those earlier states were computed using $W$, changing $W$ changes them, which changes every later state reached through the recurrence. The gradient follows this causal path from the earlier weight use, through the intermediate states, to the current loss.

For a general timestep $t$, all of these paths can be condensed into
$$
\frac{dL}{dW}
=
\sum_{t=1}^{T}
\sum_{\tau=1}^{t}
\frac{\partial L[t]}{\partial u[t]}
\left(
\prod_{k=\tau+1}^{t}
\frac{\partial u[k]}{\partial u[k-1]}
\right)
\frac{\partial u[\tau]}{\partial W}
$$
The index $t$ identifies the timestep whose loss is being differentiated. The index $\tau$ identifies an earlier or current timestep at which the shared weight affected the state. The factor $\partial u[\tau]/\partial W$ is that direct effect. The product carries the effect from state $u[\tau]$ through each transition up to $u[t]$. When $\tau=t$, the product contains no transitions and is treated as $1$, leaving the direct current-time contribution. The outer sum accumulates losses across the sequence, while the inner sum accumulates all weight uses capable of influencing each loss.

**Question.** Does temporal unrolling create a different trainable weight at every timestep?

**Answer.** Each unrolled position displays a separate use of the same trainable weight. During gradient calculation, every use contributes along its own temporal path, and those contributions are added to obtain one update for the shared $W$.

Backpropagation through time is therefore ordinary chain-rule accounting applied to a recurrent sequence. The forward pass carries membrane state from earlier timesteps into later ones. The backward pass follows those state connections in reverse, assigning part of each loss gradient to the current weight use and part to earlier uses whose effects survived through the recurrence. Temporal unrolling exposes the paths, recurrent derivatives measure how influence travels along them, and weight sharing gathers every path into a single total gradient.
