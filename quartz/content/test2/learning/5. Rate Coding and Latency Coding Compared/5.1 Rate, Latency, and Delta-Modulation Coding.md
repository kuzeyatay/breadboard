A spike train gives us a sequence of event times. The remaining question is how a real-valued quantity-such as brightness, pressure, or a neuron's activation-becomes those events. Imagine that one input value is large and another is small. An encoder must turn that difference into a temporal pattern of spikes while preserving some useful property of the original values. Rate coding preserves magnitude through spike count, latency coding preserves magnitude through first-spike timing, and delta modulation preserves changes through event timing and direction.

Rate coding represents a value by the number of spikes produced during a chosen observation window. A larger input produces spikes more frequently, so its train contains more events; a smaller input produces fewer. The decoder estimates the encoded value by counting the spikes and relating that count to the window's duration. For example, suppose two inputs are observed for the same period. One produces eight spikes and the other produces two. The eight-spike train represents the larger value because it has the higher firing rate.

The observation window is part of the representation. A short window gives the decoder an answer quickly, but the count can take only a small number of possible values. If a window contains zero, one, or two spikes, nearby input values may produce the same count. A longer window allows more spikes to accumulate, making finer distinctions possible, while delaying the moment when the decoder has a stable count. Rate coding therefore turns magnitude into repeated evidence over time: each spike contributes to an accumulating estimate.

Latency coding places the information in the time of the first spike after a reference moment. The encoder begins at a known time, and stronger inputs usually produce earlier spikes while weaker inputs produce later spikes. The decoder measures the delay from the reference moment to the first event. A short delay indicates a large value, and a long delay indicates a small value.

Consider two encoded values presented simultaneously. The stronger input might cause a spike after 2 milliseconds, while the weaker input might cause one after 8 milliseconds. The decoder can compare the arrival times as soon as those first events occur. Repeated spikes are unnecessary for this comparison because the informative feature is the initial delay. Latency coding therefore concentrates a magnitude estimate into one carefully timed event rather than spreading it across a count.

Timing needs a shared reference. A delay of 2 milliseconds has meaning only when the decoder knows when measurement began. That reference might be the onset of an input or the beginning of an encoding interval. Once the start time is shared, spike order also becomes informative: the earliest spike identifies the strongest input among a group, and later spikes indicate progressively smaller values.

Read the rate-coded pattern by looking across an interval and counting events: high input regions create denser groups of spikes, while low regions create sparser groups. Read the latency-coded pattern from the beginning of each encoding interval: the first spike moves earlier as the represented value grows and later as it falls. The real-valued input remains the same in both cases, yet one pattern preserves magnitude as spike density and the other preserves it as delay.

Delta modulation responds to another property of the signal: how it changes from one moment to the next. The encoder maintains a running reference level. As the input moves, the encoder compares the new value with that reference. When the accumulated difference reaches a chosen step, it emits an event and updates the reference by one step. Rising input produces events that indicate upward changes, while falling input produces events that indicate downward changes. A steady input produces few or no events because the reference already tracks it closely.

Imagine a brightness signal that stays near the same level, then rises rapidly, remains steady, and finally falls. Delta modulation emits a burst of upward events during the rise. The steady region becomes quiet because little change needs to be reported. The fall produces downward events. The decoder reconstructs an approximation of the signal by beginning from a known level and applying each reported upward or downward step in sequence.

In the figure, delta modulation should therefore be read by matching spikes to the slopes of the real-valued signal. Dense events appear where the signal changes quickly because several reference updates are needed to follow the movement. Sparse events appear where it changes slowly, and silence appears where it remains nearly constant. Spike count over the entire interval does not directly represent the signal's absolute height here. The sequence records the path taken by the signal: when it moved, how often it crossed an update step, and whether each crossing moved upward or downward.

The update step controls the detail of this path. A smaller step makes the reference react to smaller changes and can produce more events. A larger step produces fewer events while following the signal in coarser increments. Delta modulation therefore ties activity to change, much as a traveler might report "one floor up" or "one floor down" each time an elevator moves far enough, allowing a listener to track the journey from a known starting floor.

**Question.** If a large value produces many spikes in rate coding and an early spike in latency coding, are those spikes carrying the same message?

**Answer.** They represent the same kind of underlying quantity-magnitude-but use different evidence. Rate coding asks how many spikes occur during an interval. Latency coding asks how soon the first spike occurs after a reference time. A rate decoder needs a count and a window; a latency decoder needs an event time and a shared start time.

**Question.** How can silence carry useful information in delta modulation?

**Answer.** Silence indicates that the input has remained close enough to the encoder's current reference level that no update is required. A burst indicates movement, and the event direction indicates whether the tracked value rises or falls. Silence becomes meaningful because the decoder already knows the most recently reconstructed level.

These three schemes can be held in one mental picture by asking what the decoder measures. Rate coding measures accumulated spikes to recover magnitude. Latency coding measures the first delay to recover magnitude quickly from timing. Delta modulation follows a sequence of updates to recover the signal's movement from a known starting level. The encoder's choice determines which feature of the spike train carries meaning: count, first-spike time, or change events.
