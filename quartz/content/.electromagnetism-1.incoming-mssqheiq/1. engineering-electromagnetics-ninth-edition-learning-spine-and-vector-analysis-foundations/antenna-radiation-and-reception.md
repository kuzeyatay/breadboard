# 1.378 Antenna Radiation and Reception

Source: [[engineering-electromagnetics-9th-ed-9nbsped-compress|Engineering Electromagnetics, Ninth Edition: Learning Spine and Vector Analysis Foundations]]

Locations: Page 598, Index entries: Electromagnetic radiation, Effective area, Emitted power, Endfire array, Page 599, Index entries: Hertzian dipole, Isotropic radiator, Page 600, Index entries: Magnetic dipole, Monopole antenna, Normalized array factor, Page 601, Index entries: Radiation, Received power, Receivers, Reciprocity, Page 602, Index entries: Sidelobes, Solid angle, Thin wire antennas, Page 603, Index entries: Transmit-receive link, Uniform linear arrays

The antenna sequence develops radiation from an elementary source and then builds practical radiators by superposition. The Hertzian dipole is represented as a differential current filament with a retarded vector potential, general electric and magnetic fields, and simplified far-zone fields. Thin wire antennas are modeled as superpositions of Hertzian dipoles, with current distributions producing E-plane patterns, radiation intensity, half-wave dipoles, and monopoles. Radiation resistance, emitted power, radiation efficiency, solid angle, sidelobes, and 3-dB beamwidth quantify antenna performance. The isotropic radiator provides a reference, while magnetic dipoles and duality connect complementary source types. Arrays introduce pattern multiplication, normalized array factors, uniform linear arrays, far-zone patterns, and endfire operation. Reception uses reciprocity to connect transmitting and receiving patterns. Effective area relates incident wave power density to received power, and the transmit-receive link is represented as a two-port network. This node combines source radiation, directional patterns, arrays, and receiving behavior into one reusable antenna framework.

## Core Ideas

- A Hertzian dipole is an elementary differential-current radiation source.
- Retarded vector potential accounts for source-to-observer propagation delay.
- Far-zone fields provide the radiation terms used for antenna patterns and power.
- Thin wire antennas can be modeled by superposing Hertzian dipoles.
- Half-wave dipoles and monopoles are practical thin-wire antenna forms.
- Radiation intensity, resistance, efficiency, solid angle, beamwidth, and sidelobes characterize radiation.
- Pattern multiplication separates element behavior from array-factor behavior.
- Uniform linear arrays produce controllable far-zone patterns, including endfire cases.
- Reciprocity links transmitting and receiving antenna behavior.
- Effective area connects incident power density to received power.
