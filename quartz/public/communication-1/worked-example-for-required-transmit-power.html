Worked Example for Required Transmit Power

Source: Communications 1 Course Reader - Sampling, PAM, PCM, and Noise

Locations: Page 60, Page 61, Page 62

The final worked example develops a complete design calculation from output-quality requirement back to required transmit power. The system transmits audio with bandwidth 20 kHz, quantized using n=10 bits per sample and sampled at fs​=44.1 kHz. The channel has noise spectral density N0​/2=10−8 W/Hz and spectral efficiency η=1, while the requirement is (S/N)out​=30 dB. The solution proceeds backward through the system. First, using the output-SNR formula with M=210=1024 and converting 30 dB to linear scale as 1000, it solves for the maximum acceptable bit-error probability, obtaining Pe​=2.497×10−4. Second, the Q-function graph is used to approximate the required normalized variable as z≈3.5, which implies (S/N)in​=z2=12.25, or 10.88 dB. Third, the PCM bandwidth is found from Bpcm​=η1​nfs​=10⋅44.1×103 Hz, giving a channel noise power N=(N0​/2)Bpcm​=0.0044 W as used in the text’s notation. Finally, with S/N=12.25, the required transmit signal power is S=12.25N=0.0540 W, or 54 mW. This example is a reusable procedure for channel power budgeting from an end-to-end SNR target.

Key points

  • Given values are B=20 kHz, n=10, fs​=44.1 kHz, N0​/2=10−8 W/Hz, and η=1.
  • The required output SNR is 30 dB, which is 1000 in linear scale.
  • With M=1024, the solution finds Pe​=2.497×10−4.
  • Using the Q-function graph gives approximately z=3.5.
  • This leads to (S/N)in​=12.25, or 10.88 dB.
  • The PCM bandwidth is computed from Bpcm​=η1​nfs​.
  • The noise power is taken as N=(N0​/2)Bpcm​=0.0044 W.
  • The required transmit power is S=0.0540 W=54 mW.
