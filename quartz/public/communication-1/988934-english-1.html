Summary

This lecture segment introduces how engineers use decibels to express ratios, especially for amplifier gain, antenna gain, and RF system calculations. The core definition given is that a power ratio in decibels is calculated as 10log10​(Pout​/Pin​), so a gain of 10 dB corresponds to a tenfold power increase and a doubling of power corresponds to about 3 dB. The lecture distinguishes power-ratio dB from voltage-ratio expressions, where 20log10​(Vout​/Vin​) is used because electrical power is proportional to voltage squared. A major emphasis is preventing confusion between unitless dB and absolute power units such as dBm and dBW. The source defines dBm as 10log10​(P/1 mW) and explains examples such as 0 dBm = 1 mW, -10 dBm = 0.1 mW, and typical mobile or Wi‑Fi signals around -70 dBm. It also explains that 0 dBW equals 30 dBm because both are absolute power units with different reference levels, while plain dB cannot be converted into dBm because dB is only a ratio. The lecture also includes procedural advice: practice calculator use for base-10 logarithms, use quizzes in Canvas to reinforce dB and dBm, and ask questions publicly or through Discord so common misunderstandings can be addressed.
