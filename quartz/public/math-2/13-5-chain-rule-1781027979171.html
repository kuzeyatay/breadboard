13.5 Chain Rule

13.5 Chain Rule

Partial derivatives tell us how a function of several variables changes when one input changes and the other inputs are held fixed. That is the right first step, but it is not enough when the inputs themselves are changing. In many problems, the variables $x$, $y$, and $z$ are not independent quantities chosen separately. A point may move along a curve, so its coordinates $x(t)$, $y(t)$, and $z(t)$ all change with time. A temperature field may depend on position and time, while a thermometer moves through the field. A quantity may be written in one coordinate system and then re-expressed in another. In all these cases, the question is not only "how does the function change when one input changes?" but rather "how does the final output change when its inputs change through other variables?"

The chain rule answers this question. The word composition means that the output of one function is used as the input of another. In one-variable calculus, if

$$y = f(u), \qquad u = g(t),$$

then $y$ depends on $t$ indirectly, through $u$. The derivative is

$$\frac{dy}{dt} = \frac{dy}{du}\frac{du}{dt}.$$

In several variables, the same idea remains true, but there may be several routes through which a change can reach the final output. The multivariable chain rule is a procedure: follow every route of dependence from the final output to the variable of differentiation, multiply the derivative factors along each route, and add the route contributions.

Function of Two Variables Along a Moving Point

Let $z = f(x, y)$, where the point $(x, y)$ moves with time:

$$x = u(t), \qquad y = v(t).$$

The output is $z = f(u(t), v(t))$. A change in $t$ can change $z$ in two ways — through $x$ and through $y$. Therefore,

$$\boxed{\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}.}$$

More explicitly, using subscript notation for partial derivatives with respect to the first and second inputs:

$$\frac{d}{dt}f(u(t),v(t)) = f_1(u(t),v(t))\,u'(t) + f_2(u(t),v(t))\,v'(t).$$
Common mistakes: Computing only one term (pretending only one coordinate changes), or evaluating the partial derivatives at the wrong point. The partial derivatives $\partial z/\partial x$ and $\partial z/\partial y$ must be evaluated at the current input point $(x(t), y(t))$.

Example: Ascent and Descent Along a Path

Example 1

Let the height of a landscape be $H(x,y) = \sin x \sin y$. A person moves along the path $y = x^2 - 2$ with speed $5$ in the $xy$-plane, and is currently at $(-1, -1)$.

Differentiating the path equation with respect to $t$:

$$\frac{dy}{dt} = 2x\frac{dx}{dt} \quad\Longrightarrow\quad \text{at } x = -1: \quad \frac{dy}{dt} = -2\frac{dx}{dt}.$$

The speed condition $\left\|\left\langle \frac{dx}{dt}, \frac{dy}{dt}\right\rangle\right\| = 5$ gives:

$$5 = \sqrt{\left(\frac{dx}{dt}\right)^2 + 4\left(\frac{dx}{dt}\right)^2} = \sqrt{5}\left|\frac{dx}{dt}\right| \quad\Longrightarrow\quad \left|\frac{dx}{dt}\right| = \sqrt{5}.$$

The partial derivatives of $H$ at $(-1,-1)$:

$$H_x(-1,-1) = -\cos(1)\sin(1), \qquad H_y(-1,-1) = -\sin(1)\cos(1).$$

Applying the chain rule with $dx/dt = \sqrt{5}$, $dy/dt = -2\sqrt{5}$:

$$\frac{dH}{dt} = \sqrt{5}\sin(1)\cos(1) > 0 \quad \text{(uphill).}$$

Therefore the descending velocity is

$$\left\langle \frac{dx}{dt},\, \frac{dy}{dt} \right\rangle = \left\langle -\sqrt{5},\, 2\sqrt{5} \right\rangle, \qquad \frac{dH}{dt} = -\sqrt{5}\sin(1)\cos(1) < 0.$$

Direct and Indirect Dependence

Suppose $T = e^{-tz}$ and depth $z = f(t)$. The variable $t$ affects $T$ both directly and through $z$. The chain rule gives:

$$\frac{dT}{dt} = \frac{\partial T}{\partial t} + \frac{\partial T}{\partial z}\frac{dz}{dt}.$$

Since $\partial T/\partial t = -z e^{-tz}$ and $\partial T/\partial z = -t e^{-tz}$:

$$\frac{dT}{dt} = -f(t)\,e^{-t f(t)} - t f'(t)\,e^{-t f(t)}.$$

The first term is the direct time effect at fixed depth; the second is the effect of moving to a different depth.

Notation. A partial derivative only has a clear meaning when we know which variables are held fixed. Write $\left(\dfrac{\partial w}{\partial z}\right)_{x,y}$ when both $x$ and $y$ are fixed. If $y$ depends on $z$ with $x$ fixed: $$\left(\frac{\partial w}{\partial z}\right)_x = \frac{\partial w}{\partial y}\left(\frac{\partial y}{\partial z}\right)_x + \frac{\partial w}{\partial z}.$$

Two Independent Variables

Suppose $z = f(x,y)$, $x = u(s,t)$, $y = v(s,t)$. Then:

$$\frac{\partial z}{\partial s} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial s} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial s}, \qquad \frac{\partial z}{\partial t} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial t} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial t}.$$
Example 2

Let $z = \sin(x^2 y)$, $x = st^2$, $y = s^2 + 1/t$. Then:

$$\frac{\partial z}{\partial x} = 2xy\cos(x^2 y), \qquad \frac{\partial z}{\partial y} = x^2\cos(x^2 y).$$
$$\frac{\partial x}{\partial s} = t^2, \quad \frac{\partial y}{\partial s} = 2s, \qquad \frac{\partial x}{\partial t} = 2st, \quad \frac{\partial y}{\partial t} = -\frac{1}{t^2}.$$

Since $x^2 y = s^4 t^4 + s^2 t^3$:

$$\frac{\partial z}{\partial s} = (4s^3 t^4 + 2st^3)\cos(s^4 t^4 + s^2 t^3),$$
$$\frac{\partial z}{\partial t} = (4s^4 t^3 + 3s^2 t^2)\cos(s^4 t^4 + s^2 t^3).$$

Abstract Outer Functions

Let $u = x^2 y$, $v = x + 2y$. Then:

$$\frac{\partial}{\partial x}f(x^2 y,\, x + 2y) = 2xy\, f_1(x^2 y,\, x+2y) + f_2(x^2 y,\, x+2y),$$
$$\frac{\partial}{\partial y}f(x^2 y,\, x + 2y) = x^2 f_1(x^2 y,\, x+2y) + 2f_2(x^2 y,\, x+2y).$$
Key point. $f_1(x^2 y, x+2y)$ means "differentiate $f$ with respect to its first input, then evaluate at the pair $(x^2 y,\, x+2y)$." It does not mean differentiate with respect to $x$.

Dependency Charts: The Moving Thermometer

Let $T = T(x, y, z, t)$ be temperature at position $(x,y,z)$ and time $t$, with $x = x(t)$, $y = y(t)$, $z = z(t)$. Then:

$$\frac{dT}{dt} = \frac{\partial T}{\partial x}\frac{dx}{dt} + \frac{\partial T}{\partial y}\frac{dy}{dt} + \frac{\partial T}{\partial z}\frac{dz}{dt} + \frac{\partial T}{\partial t}.$$
Example 3

Let $T(x,y,z,t) = \dfrac{xy}{1+z}(1+t)$, with $x = t$, $y = 2t$, $z = t - t^2$. At $t = 1$: $x=1$, $y=2$, $z=0$.

$$T_x = 4, \quad T_y = 2, \quad T_z = -4, \quad T_t = 2.$$
$$\frac{dx}{dt} = 1, \quad \frac{dy}{dt} = 2, \quad \frac{dz}{dt} = -1.$$
$$\frac{dT}{dt} = 4(1) + 2(2) + (-4)(-1) + 2 = 14 \text{ °C/hr.}$$

Complex Dependency Structures

If $z$ depends on $u$, $v$, $r$; $u$ and $v$ depend on $x$, $y$, $r$; and $r$ depends on $x$ and $y$, then following every route from $z$ to $x$:

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial u}\frac{\partial u}{\partial r}\frac{\partial r}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial r}\frac{\partial r}{\partial x} + \frac{\partial z}{\partial r}\frac{\partial r}{\partial x}.$$
Procedure: Draw the dependency structure, follow every path to the variable of differentiation, multiply along each path, and add.

Higher-Order Derivatives

Let $z = f(x,y)$, $x = 2s+3t$, $y = 3s-2t$. Then $z_s = 2f_1 + 3f_2$ and $z_t = 3f_1 - 2f_2$. Applying the chain rule again:

$$z_{ss} = 4f_{11} + 12f_{12} + 9f_{22},$$
$$z_{st} = 6f_{11} + 5f_{12} - 6f_{22},$$
$$z_{tt} = 9f_{11} - 12f_{12} + 4f_{22}.$$

For general linear substitution $x = as + bt$, $y = cs + dt$:

$$z_{tt} = b^2 f_{11} + 2bd\, f_{12} + d^2 f_{22}.$$
Warning. Every derivative of $f$ in these formulas is evaluated at $(x,y) = (2s+3t,\, 3s-2t)$, not at $(s,t)$. The mixed term is $2bd\,f_{12}$, not $bd\,f_{12}$ — it receives contributions from both $f_{12}$ and $f_{21}$.

Nonlinear Inner Variables

Let $u = x^2 - y^2$, $v = xy$, $z = f(u,v)$. Then $z_y = f_1 u_y + f_2 v_y = -2y f_1 + x f_2$. Differentiating with respect to $x$:

$$z_{xy} = f_2(u,v) - 4xy\, f_{11}(u,v) + 2(x^2 - y^2)f_{12}(u,v) + xy\, f_{22}(u,v),$$

where all derivatives of $f$ are evaluated at $(u,v) = (x^2 - y^2,\, xy)$, not at $(x,y)$.

Euler's Theorem for Homogeneous Functions

A function $f(x_1, \ldots, x_n)$ is positively homogeneous of degree $k$ if

$$f(t x_1, \ldots, t x_n) = t^k f(x_1, \ldots, x_n), \qquad t > 0.$$

Differentiating both sides with respect to $t$ and setting $t = 1$ gives Euler's Theorem:

$$\boxed{\sum_{i=1}^{n} x_i f_i(x_1, \ldots, x_n) = k\, f(x_1, \ldots, x_n).}$$

For example, $f(x,y) = x^2 + xy - y^2$ is homogeneous of degree 2, so $x f_x + y f_y = 2f$.

Polar Coordinates

With $x = r\cos\theta$, $y = r\sin\theta$ and $z = f(x,y)$:

$$z_r = f_x \cos\theta + f_y \sin\theta,$$
$$z_\theta = -r f_x \sin\theta + r f_y \cos\theta.$$

Repeated chain rule gives the polar form of the Laplacian:

$$f_{xx} + f_{yy} = z_{rr} + \frac{1}{r}z_r + \frac{1}{r^2}z_{\theta\theta}.$$
Warning. Do not transform higher-order derivatives by simply replacing symbols. The extra terms $(1/r)z_r$ and the factor $1/r^2$ arise because polar coordinates do not measure distance the same way in radial and angular directions.

Velocity in Cylindrical Coordinates

With position $\mathbf{r}(t) = r(t)\,\hat{\mathbf{r}}(\theta(t))$, differentiating using both product rule and chain rule:

$$\mathbf{v} = \dot{r}\,\hat{\mathbf{r}} + r\dot{\theta}\,\hat{\boldsymbol{\theta}}.$$

The term $\dot{r}\,\hat{\mathbf{r}}$ is radial velocity; $r\dot{\theta}\,\hat{\boldsymbol{\theta}}$ is tangential velocity.

Common error: Writing $\dot{r}\,\hat{\mathbf{r}} + \dot{\theta}\,\hat{\boldsymbol{\theta}}$ and forgetting the factor $r$. Angular speed $\dot{\theta}$ is in radians per unit time; tangential speed is arc length per unit time, which is $r\dot{\theta}$.
Example 4

Let $r = 2 - 0.1t$, $\theta = 0.5t$. At $t = 2$: $r = 1.8$, $\dot{r} = -0.1$, $\dot{\theta} = 0.5$.

$$\mathbf{v} = -0.1\,\hat{\mathbf{r}} + (1.8)(0.5)\,\hat{\boldsymbol{\theta}} = -0.1\,\hat{\mathbf{r}} + 0.9\,\hat{\boldsymbol{\theta}}.$$

Summary. Identify what depends on what → follow every route → multiply along each route → add contributions. This procedure handles paths, coordinate changes, higher-order derivatives, homogeneous functions, and physical velocity all by the same logic.
