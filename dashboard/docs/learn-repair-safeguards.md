# Learn recovery and acceptance policy

`accepted-critic-residues.json` belongs to the live garden. Fresh and resumed
builds exclude it. Promotion, including promotion used for rollback, copies the
latest live bytes immediately before swapping directories. If no live file
exists, a stale candidate cannot restore one. Reports snapshot the exact policy
read by the critic, its hash, effective settings, recorded exceptions and the
findings each exception matched. Accepted findings remain visible but do not
consume repair rounds. Deterministic validation still applies.

Syllabus evidence recovery runs when any unit is refused. Receipts distinguish
newly recovered coverage, unchanged coverage, regression and zero teachable
units. An unchanged partial decision can retain its supported units; it must
not claim a recovery. Losing previously supported units stops planning.

An explicit refusal of a lesson's own objective gets a bounded repair before
strict export. The critic also offers re-anchoring for source and explanation
gaps. Each repair instance makes at most one evidence-selection call per unit,
using at most 12 existing canonical anchors from that unit's sources and 36,000
characters of complete passages. It cannot add a book, invent an anchor, delete
a claim, simplify the objective, or change required artifacts. Contract bindings
and the rewritten page are validated together and restored together on failure.

This is a bounded repair, not guaranteed recovery: evidence outside the offered
anchors remains unresolved. Existing visual/formula review provenance cannot be
rewritten by an evidence repair; if those approvals would become stale, the
candidate fails validation and needs the corresponding review refreshed. No
validator accepts new evidence merely because its vocabulary matches the topic.

Teaching checks reject internal pipeline prose and explicit central refusals.
Optional scope limits remain allowed. Notation continuity distinguishes use from
an explanatory bridge and keeps unexplained dependencies unresolved on later
pages. This deterministic check warns; it does not certify comprehension.
Semantic planning/review additionally checks prerequisite closure, backward
references, complete process examples and whether the learner can apply the
promised idea. These safeguards do not replace reviewing the generated lessons.
