# ASCII Magic

Vendored from ascii-magic-art@1.1.0 on npm.
Source: https://github.com/kailashsr38/ascii-magic-art
Documentation: https://www.ascii-magic.com/ascii/docs

The runtime, lib and pieces directories are unmodified upstream code.
Keep LICENSE and NOTICE with these files, including the two Unsplash scene notices.
The adjacent breadboard-player.js is Breadboard's integration adapter.

To update, unpack the pinned npm package and run scripts/sync-ascii-magic.mjs with its directory.
No network connection is needed to browse or play the installed library.
