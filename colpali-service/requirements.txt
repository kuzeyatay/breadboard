# 3.14 wheels for Windows, and 3.14 is this repository's default interpreter —
# so scripts/setup-colpali.mjs provisions .runtime/colpali-venv on 3.13 through
# uv rather than using whatever `python` happens to be.
#
# torch is NOT pinned to a CUDA build here. The setup script installs it first
# from the cu124 index; leaving it unqualified in this file means a CPU-only
# machine still gets a working (slower) service instead of a failed install.
