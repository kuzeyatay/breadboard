# Accessibility

Provide a useful title, concise description, native keyboard controls,
associated labels, visible focus, units, non-color-only distinctions, and
reset. Explain the important graphical state in text. Three-dimensional scenes
need an explicit non-visual description and important values outside Canvas.

Animation must remain understandable when motion is reduced or paused. No
essential action may depend only on pointer dragging. Keep contrast compatible
with both Breadboard themes and avoid hiding overflow that contains controls.
