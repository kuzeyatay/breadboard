# Interaction design

Each control must change an observable part of the model. Prefer one to four
high-value controls to a parameter dashboard. Pair changing values with labels,
units, and finite numerical readouts when useful.

Animated mini-apps place compact circular play/pause and reset buttons beside
the H1. Generated code pauses while hidden and honors reduced motion. Do not
create decorative motion with no explanatory value.

At 375 CSS pixels, controls and result strips stack without clipping or
horizontal overflow. Dragging may supplement keyboard and labelled controls but
cannot be the only way to inspect 3D state. Keep the initial state informative.
